CMPS 3600 · Templates

Starter templates

Blank starting files for new C and C++ programs.

View code on GitHubREADME

What I did

  • Kept sample.c with the headers most labs need and baseProg.cpp with an empty main.

What I used

  • C
  • C++

Libraries

Header or moduleWhat it is for
unistd.hPOSIX calls such as read, write, fork, pipe and sleep

C standard library: stdio.h, stdlib.h, string.h.

C++ standard library: iostream.

How to build and run

From the folder with the code:

gcc -o sample sample.c

Requires: Linux with gcc and POSIX threads. The graphical labs also need the X11 development headers (sudo apt install libx11-dev libxext-dev on Ubuntu). Every folder has a Makefile.
