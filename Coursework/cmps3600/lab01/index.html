CMPS 3600 · Lab 1

System calls instead of the C++ library

A short C++ program rewritten in C with only system calls. It asks for a name and a number, adds up 1 to that number, and writes both to a file named log, using read, write and open in place of cin, cout and ofstream.

View code on GitHubREADME

What I did

  • Wrote lab1.cpp, the C++ version with cin, cout and an ofstream.
  • Rewrote it as lab1.c, keeping each C++ line as a comment above the system call that replaces it.
  • Read the input with read(0, ...), converted the number with atoi, and formatted the result line with sprintf before writing it.
  • Opened log with open("log", O_CREAT|O_RDWR|O_TRUNC, ...) and checked for -1.

How to build and run

From the folder with the code:

make
./lab1c
cat log

Requires: Linux with gcc and POSIX threads. The graphical labs also need the X11 development headers (sudo apt install libx11-dev libxext-dev on Ubuntu). Every folder has a Makefile.
