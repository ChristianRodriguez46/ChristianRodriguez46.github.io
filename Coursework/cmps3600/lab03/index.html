CMPS 3600 · Lab 3

Signal handlers

Signal handling between a parent and child. The child writes half of a message to log, then waits in sigsuspend until SIGUSR1 arrives, and finishes the message. The parent sends SIGTERM first, which stays blocked, so only SIGUSR1 wakes the child.

View code on GitHubREADME

What I did

  • Blocked every signal with sigfillset and sigprocmask before forking, so none arrive early.
  • Installed one handler for SIGTERM and SIGUSR1 with sigaction; it writes a marker into the log.
  • Removed SIGUSR1 from the mask and passed it to sigsuspend, so the child sleeps until that signal alone arrives.
  • Sent both signals from the parent with kill and printed the child's exit code after wait.
  • Wrote practice/mySignals.c, which catches SIGCHLD when a child ends.

How to build and run

From the folder with the code:

make
./lab3
cat log

Requires: Linux with gcc and POSIX threads. The graphical labs also need the X11 development headers (sudo apt install libx11-dev libxext-dev on Ubuntu). Every folder has a Makefile.
