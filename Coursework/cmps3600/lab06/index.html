CMPS 3600 · Lab 6

Producer and consumer threads

The producer-consumer problem with two threads and a one-character buffer. The producer reads a file one character at a time and the consumer writes each one to log. Two System V semaphores make them take turns, so no character is lost or written twice.

View code on GitHubREADME

What I did

  • Started from the instructor's echo.c, which has no synchronization and drops or repeats characters.
  • Created a two-semaphore set, one for the producer and one for the consumer, and gave each thread its own grab and release operations.
  • Had each thread release the other's semaphore after its turn, so the two strictly alternate.
  • Took the number of characters to copy from the command line, capped at the length of poem.
  • Kept bbphase2.c, phase 2 of the semester project (see lab 15), and wrote practice/mythreads.c, two threads that alternate with POSIX semaphores.

How to build and run

From the folder with the code:

make
./bblab6
cat log

Requires: Linux with gcc and POSIX threads. The graphical labs also need the X11 development headers (sudo apt install libx11-dev libxext-dev on Ubuntu). Every folder has a Makefile.

This program opens an X11 window

It needs an X server on the computer you are looking at. On Linux that is already part of the desktop. On a Mac or a Windows PC, or when the program runs on another machine over SSH, see Setting up X11 for what to install and how to check it works.
