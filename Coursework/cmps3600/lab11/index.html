CMPS 3600 · Lab 11

Memory-mapped files

Copying part of a file through memory maps. bblab11.c maps the input file with mmap, rounding the offset down to a page boundary as mmap requires, copies the requested bytes into an anonymous mapping and writes them to the output file.

View code on GitHubREADME

What I did

  • Started from the instructor's maptest.c, which prints part of a file to the screen.
  • Changed the arguments to <infile> <outfile> <offset> <length>, with offset and length optional.
  • Rejected offsets past the end of the file and trimmed lengths that run past it.
  • Added a second mapping with MAP_SHARED | MAP_ANONYMOUS, copied into it with memcpy, wrote it to the output file and unmapped both.

How to build and run

From the folder with the code:

./lab11 article out.txt 5 25
cat out.txt

Requires: Linux with gcc and POSIX threads. The graphical labs also need the X11 development headers (sudo apt install libx11-dev libxext-dev on Ubuntu). Every folder has a Makefile.
