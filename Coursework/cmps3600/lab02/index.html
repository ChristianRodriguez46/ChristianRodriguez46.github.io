CMPS 3600 · Lab 2

Processes with fork and wait

bblab2.c forks a child process that computes a Fibonacci number recursively and writes it, with a timestamp, to log. The parent waits for the child and prints its PID and exit code. The rest of the folder is the week's examples of fork, wait, signals and error handling.

View code on GitHubREADME

What I did

  • Read the term number from the command line and printed a usage message when it is missing.
  • Forked a child that opens log, writes the time with strftime, then writes fib(n).
  • Had the child exit with the term number as its exit code, and the parent read it back with wait, WIFEXITED and WEXITSTATUS.
  • Wrote practice/myfork.c, a small fork-and-wait exercise.

How to build and run

From the folder with the code:

make
./lab2 9
cat log

Requires: Linux with gcc and POSIX threads. The graphical labs also need the X11 development headers (sudo apt install libx11-dev libxext-dev on Ubuntu). Every folder has a Makefile.
