CMPS 3600 · Lab 13

Intersection, continued

The lab 9 intersection, now with cars that can be added and removed while it runs. All eight car threads start with the program; A activates one and D parks the highest-numbered one, and the mutex still keeps the intersection to one car at a time.

View code on GitHubREADME

What I did

  • Gave each car an active flag; an inactive car's thread sleeps briefly and checks again.
  • Wrote init_single_car to start a car just outside the window in its own lane, with a random size and speed.
  • Handled A and D in check_keys, keeping a count of active cars between 0 and 8.
  • Kept the intersection mutex from lab 9, so cars still cross one at a time.

  • POSIX threads
  • Mutexes

How to build and run

From the folder with the code:

make
./bbcars

Requires: Linux with gcc and POSIX threads. The graphical labs also need the X11 development headers (sudo apt install libx11-dev libxext-dev on Ubuntu). Every folder has a Makefile.

This program opens an X11 window

It needs an X server on the computer you are looking at. On Linux that is already part of the desktop. On a Mac or a Windows PC, or when the program runs on another machine over SSH, see Setting up X11 for what to install and how to check it works.
