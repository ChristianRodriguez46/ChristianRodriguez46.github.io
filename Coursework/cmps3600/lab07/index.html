CMPS 3600 · Lab 7

Dining philosophers

The dining philosophers problem: five threads share five forks and each needs two to eat. Each philosopher picks up its lower-numbered fork first, which rules out the circular wait that causes deadlock. The forks are System V semaphores.

View code on GitHubREADME

What I did

  • Converted the class version, eat.c, from POSIX semaphores to a set of five System V semaphores.
  • Ordered each philosopher's two forks so the lower number is taken first.
  • Wrapped the two grabs in a monitor mutex so a philosopher takes both forks in one step.
  • Printed every meal with the current counts and stopped all threads once one philosopher has eaten more than the limit given on the command line.
