# CMPS 3560: Artificial Intelligence

Expert systems, logic, fuzzy sets, neural networks and evolutionary algorithms.

Languages and tools: Python, C++, Prolog.

## Requirements

Python 3 for the Python labs, `g++` for the C++ labs, and SWI-Prolog or GNU Prolog for labs 4 and 5.
