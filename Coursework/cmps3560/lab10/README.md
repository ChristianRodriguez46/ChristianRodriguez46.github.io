# Genetic algorithm

**CMPS 3560 Artificial Intelligence**, Lab 10

Read this lab with snapshots and notes on every file: [https://christianrodriguez46.github.io/Coursework/cmps3560/lab10/](https://christianrodriguez46.github.io/Coursework/cmps3560/lab10/)

## What it does

`lab10.py` solves the Max-Ones problem (evolve a 32-bit string of all ones) with a population of 25, tournament selection, one-point crossover and mutation, printing the best fitness each generation. `MDlab10.py` is the same solution split into notebook cells with explanations.

## How to run

From this folder:

```bash
python3 lab10.py
```

Requires: Python 3 for the Python labs, `g++` for the C++ labs, and SWI-Prolog or GNU Prolog for labs 4 and 5.
