CMPS 3560 · Lab 8

Pocket perceptron

A perceptron in C++ that separates the last 50 rows of the normalized Iris data (+1) from the first 100 (-1). It shuffles the samples every epoch, updates the weights on each mistake, and keeps the weights from the best epoch (the pocket algorithm). The classes are not linearly separable, so training runs the full 1,000 epochs and ends near 90% accuracy.

View code on GitHubREADME

What I did

  • Loaded the CSV into Sample records with a bias input of 1, checked for exactly 150 rows with assert, and printed the first and last rows.
  • Initialized the weights at random in [-0.5, 0.5] with mt19937 and reshuffled the data each epoch with std::shuffle.
  • Applied the perceptron rule w += α·y·x with α = 0.05 whenever the hard limiter's ±1 output was wrong, and printed the misclassifications for each epoch.
  • Kept the weights from the epoch with the fewest misclassifications and printed that accuracy and weight vector at the end.
