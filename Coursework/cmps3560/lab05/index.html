CMPS 3560 · Lab 5

Expert system for choosing a training medium

An interactive expert system in Prolog that recommends a training medium (workshop, lecture, videocassette or role play) from yes/no answers about the work environment, the job and whether feedback is required. It tries each recommendation in turn, asks only the questions it needs, and remembers each answer with assert so nothing is asked twice.

View code on GitHubREADME

What I did

  • Adapted the animal-identification expert system from J. R. Fisher's Prolog tutorial (linked in the file header), keeping its ask, verify and undo predicates.
  • Wrote the Media Advisor rules: stimulus_situation and stimulus_response classify the environment and the job, and each medium rule combines them with a feedback question.
  • Ordered hypothesize to try workshop, lecture, videocassette and role play, falling back to unknown, and cleared the stored answers with undo after each consultation.

How to build and run

From the folder with the code:

swipl lab5.pl
?- go.

Requires: Python 3 for the Python labs, g++ for the C++ labs, and SWI-Prolog or GNU Prolog for labs 4 and 5.
