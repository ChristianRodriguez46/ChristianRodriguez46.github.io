# Expert system for choosing a training medium

**CMPS 3560 Artificial Intelligence**, Lab 5

## What it does

`lab5.pl` is an interactive Prolog expert system. It asks yes/no questions about the training situation and recommends a medium: workshop, lecture, videocassette or role play.

## How to run

From this folder:

```bash
swipl lab5.pl
?- go.
```

Requires: Python 3 for the Python labs, `g++` for the C++ labs, and SWI-Prolog or GNU Prolog for labs 4 and 5.

- Expert systems
- Backward chaining
- Interactive Prolog
