# Fuzzy sets

**CMPS 3560 Artificial Intelligence**, Lab 6

## What it does

`Lab6.py` defines fuzzy sets as piecewise-linear shapes, implements membership and inverse membership functions with test cases, and uses them to recommend how many bottles of water to bring based on distance walked and temperature.

## How to run

From this folder:

```bash
python3 Lab6.py
```

Requires: Python 3 for the Python labs, `g++` for the C++ labs, and SWI-Prolog or GNU Prolog for labs 4 and 5.

## Concepts

- Fuzzy logic
- Membership functions
