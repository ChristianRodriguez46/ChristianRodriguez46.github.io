CMPS 3560 · Lab 6

Fuzzy sets

Fuzzy sets written as lists of (membership, value) points, with a membership function and an inverse membership function that both work from the nearest point, each checked against expected values. A one-rule inference then recommends how much water to bring after walking 3 km at 80F.

View code on GitHubREADME

What I did

  • Defined the fuzzy sets bottle, short, moderate and hot as tuples of (membership, crisp value) points.
  • Wrote membership, which returns the membership of the closest crisp value, and inverseMembership, which returns the crisp value whose membership is closest.
  • Printed five test cases for each function, with the expected result in a comment.
  • Combined the distance and temperature memberships with max and mapped the result back through bottle to get the recommendation, 0.5 bottles for 3 km at 80F.
