CMPS 3560 · Lab 1

Rule-based classifier for iris flowers

A one-rule expert system for Iris flowers: a petal measurement above 1.6 means Virginica, anything else Versicolor. It classifies the 100 flowers in iris.csv, prints each prediction next to the true label, and reports 94% accuracy on this data.

View code on GitHubREADME

What I did

  • Wrote main, which reads iris.csv into a 100 by 2 array with the templated readCSV helper and applies the rule to every row.
  • Picked the threshold by trying values, with a comment noting that 1.6 to 1.7 worked best. The column holds Iris petal widths, although the code calls it petal_length.
  • Counted the predictions that match the label column and printed the accuracy.
  • Added a usage message and exit code 1 when no file name is given.

How to build and run

From the folder with the code:

g++ -o expsys expsys.cpp
./expsys iris.csv

Requires: Python 3 for the Python labs, g++ for the C++ labs, and SWI-Prolog or GNU Prolog for labs 4 and 5.
