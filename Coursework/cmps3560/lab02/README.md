## What it does

`Lab2.py` starts from a database of known facts ("looks", "swims", "quacks") and a set of if-then rules, and applies the rules repeatedly, printing each step, until no new facts can be added.

## How to run

From this folder:

```bash
python3 Lab2.py
```

Requires: Python 3 for the Python labs, `g++` for the C++ labs, and SWI-Prolog or GNU Prolog for labs 4 and 5.

- Forward chaining
- Rule-based inference
