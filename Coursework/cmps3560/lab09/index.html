CMPS 3560 · Lab 9

Multiclass neural network

A small neural network written from scratch in C++ that classifies the three Iris species: 4 inputs, 3 sigmoid hidden neurons and 3 sigmoid outputs, trained with backpropagation and stochastic gradient descent. It prints the mean absolute deviation error every epoch and the final training accuracy, which landed between 94% and 99% in test runs here.

View code on GitHubREADME

What I did

  • Wrote the forward pass, backpropagation (sgd), and the mad and accuracy helpers by hand, with fixed-size std::array weight matrices for the 3 by 5 hidden layer and 3 by 4 output layer.
  • Initialized the weights with Xavier-uniform limits, sqrt(6 / (fan in + fan out)), and shuffled the data once with mt19937.
  • Trained for up to 1,000 epochs with α = 0.05, doubled it after epoch 100, and stopped early if training accuracy reached 100%.
  • Read one-hot labels from iris.csv, three label columns after the four features.

How to build and run

From the folder with the code:

g++ -std=c++17 -O2 -o lab9_nn lab9_nn.cpp
./lab9_nn iris.csv

Requires: Python 3 for the Python labs, g++ for the C++ labs, and SWI-Prolog or GNU Prolog for labs 4 and 5.
