CMPS 3120 · Lab 1

Stack-sortable strings and permutations

Generates every valid push/pop sequence (a *stacky string*) of length 2n by backtracking and checks the count against the Catalan-number formula, including C[16] and C[32]. A second part lists the permutations a stack can produce and tests random permutations, but in this version its stack pointer starts at 1 and is never decremented, so those permutations repeat values.

View code on GitHubREADME

What I did

  • Started from the instructor's skeleton and filled in the marked lines: the '+' branch of the recursive stackystrhelper and the Catalan formula in stackystrformula.
  • Implemented the handout's formula step by step, multiplying by (4i - 2) and then dividing by (i + 1), so every intermediate value stays whole and C[32] = 55534064877048198 fits in an unsigned long long.
  • Saved a run with n = 4 in output.txt: 14 stacky strings, matching C[4] = 14.

How to build and run

From the folder with the code:

gcc -o lab1 lab1.c
./lab1 4

Requires: A C compiler such as gcc. The assignment needs Python 3 with NumPy, SciPy and Matplotlib.
