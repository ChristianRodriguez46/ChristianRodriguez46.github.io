CMPS 3120 · Assignment

Sensor network clustering

Places 5 cluster heads and N sensor nodes at random in a 100 by 100 area, assigns each node to a random cluster head, and counts the hops from each node to its head with breadth-first search over links of up to 30 units. A tabu search then moves nodes to their nearest cluster head when that does not add hops, and a side-by-side plot over the Voronoi diagram of the cluster heads shows the clusters before and after.

View code on GitHubREADME

What I did

  • Built the communication graph as an adjacency matrix from pairwise distances (cdist) and wrote calculate_hop_count, a BFS from a node to its cluster head.
  • Wrote the tabu search loop: nodes are visited in random order, each move (node, old head, new head) is checked against a list of the last 100 moves, and a move is kept if the node's hop count does not go up.
  • Stopped the search after a pass with no accepted move or after 200 passes, then recomputed the hop counts and printed the totals before and after.
  • Drew both clusterings with Matplotlib and SciPy's voronoi_plot_2d, coloring nodes by their new cluster, and saved the figure to voronoi_optimization_updated.png.
  • Took the node count from the command line, with 50 as the default, and fixed the NumPy random seed (42) so the positions repeat between runs.

How to build and run

From the folder with the code:

python3 Assignment.py 50

Requires: A C compiler such as gcc. The assignment needs Python 3 with NumPy, SciPy and Matplotlib.
