CMPS 3120 · Lab 8

Shortest distances with BFS

Generates a random graph and measures the distance between two groups of vertices, the first n1 and the last n2, with breadth-first search. Method 1 runs one BFS from each vertex in the first group, and method 2 contracts each group into one vertex and runs BFS once. A leftover line in the edge generator corrupts the adjacency lists, so the printed lists contain self-loops and the two methods can disagree.

What I did

  • Started from the instructor's skeleton (its first line lists the lines to fill in).
  • Wrote the part of gengraph that orders each new edge so u < v and adds u to v's adjacency list, but a leftover G[v] = p; right after it replaces v's list with u's.
  • Filled in the queue allocation and marking the start vertex as visited in BFS.
  • Saved a run with n = 12, m = 15, n1 = 3 and n2 = 2 in output.txt.
