# Shortest distances with BFS

**CMPS 3120 Algorithm Analysis**, Lab 8

## What it does

Generates a random graph with n vertices and m edges, prints its adjacency lists, and computes distances between two groups of vertices with breadth-first search, first one source at a time and then all at once.

## How to run

From this folder:

```bash
gcc -o lab8 asgn8.c
./lab8 12 15 3 2
```

Requires: A C compiler such as `gcc`. The assignment needs Python 3 with NumPy, SciPy and Matplotlib.

## Concepts

- Graphs
- Breadth-first search
- Adjacency lists
