CMPS 3120 · Lab 2

Guessing games against a black box

Plays four games against the instructor's black box, which hides a number between 1 and 100,000,000: linear search, random guessing, and two halving strategies where the only hint is whether a guess is closer than the previous one. Each game is timed, and in the saved run the two halving strategies finish in about 2 microseconds while linear and random search take about 0.4 seconds.

View code on GitHubREADME

What I did

  • Started from the instructor's skeleton and filled in the marked guesses: the check in the random search playgame2, the guess at R in playgame3, and the mirrored guess G in playgame4.
  • Linked against the instructor's black-box object file (not included), which provides startgame, guess and verifysoln.
  • Saved a run in output.txt where all four answers pass verifysoln.

What I used

  • C
  • Binary search
  • Linear search
  • Randomized search
  • Timing

Concepts:

  • Linear vs. binary search

Libraries

C standard library: stdio.h, stdlib.h, time.h.

How to build and run

From the folder with the code:

gcc -o lab2 lab2.c blackbox1.o  # blackbox1.o is from the course server
./lab2

Requires: A C compiler such as gcc. The assignment needs Python 3 with NumPy, SciPy and Matplotlib.

Links against an instructor-provided object file that is not included here, so this lab only builds on the course server. output.txt shows a complete run.
