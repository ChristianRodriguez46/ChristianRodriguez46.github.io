CMPS 3120 · factorial.c

Factorial calculator

Reads an integer and prints its factorial, computed in a loop into an unsigned long long, or an error message for a negative number. Inputs above 20 overflow the 64-bit result and wrap around.

View code on GitHub

What I used

  • C
  • Loops
  • Input validation

Libraries

C standard library: stdio.h.

How to build and run

Requires: A C compiler such as gcc. The assignment needs Python 3 with NumPy, SciPy and Matplotlib.
