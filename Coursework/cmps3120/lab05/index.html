CMPS 3120 · Lab 5

Rebuilding a BST from its preorder listing

Builds a random binary search tree of three-digit keys, stores its preorder listing in an array, and rebuilds the tree from that array in O(n) time with two explicit stacks. It then checks that the result is a BST and looks up inorder and preorder successors, including keys that have none.

View code on GitHubREADME

What I did

  • Started from the instructor's skeleton and filled in the right-subtree check in isBST and the right-child case in preorderSuccessor.
  • Ran the skeleton's tests, which compare the rebuilt tree's preorder listing with the array and look up successors for random keys and for keys with no successor.
  • Saved a run with n = 100 in output.txt, where the listings match and the tree passes the BST check.

How to build and run

From the folder with the code:

gcc -o lab5 Asg5.c
./lab5 100

Requires: A C compiler such as gcc. The assignment needs Python 3 with NumPy, SciPy and Matplotlib.
