# Rebuilding a BST from its preorder listing

**CMPS 3120 Algorithm Analysis**, Lab 5

## What it does

Builds a random binary search tree, stores its preorder listing in an array, reconstructs the tree from that listing, verifies it is a valid BST, and finds the inorder and preorder successor of a key.

## How to run

From this folder:

```bash
gcc -o lab5 Asg5.c
./lab5 100
```

Requires: A C compiler such as `gcc`. The assignment needs Python 3 with NumPy, SciPy and Matplotlib.
