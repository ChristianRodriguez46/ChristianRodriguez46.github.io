CMPS 3120 · Lab 7

Subset sum: exhaustive search vs. hashing

Splits N random five-digit numbers as evenly as possible by finding the largest subset sum that does not go over half the total. An exhaustive search is compared with a version that records each (index, sum) state in a hash table with linear probing so repeated states are skipped, and the table is then used to print the chosen numbers.

View code on GitHubREADME

What I did

  • Started from the instructor's skeleton (its first line lists the lines to fill in) and filled in the exclude branch of the exhaustive search exhs.
  • Wrote the hash function h as (100003 * i + 103 * sum) % s, following the lab handout.
  • Filled in the include branch of hashs, which stores (i, sum + A[i]) with its inclusion flag before recursing, so findsol can trace the chosen numbers back.
  • Saved runs for N = 16 and N = 32 in output.txt, where both methods find the same best sum.
