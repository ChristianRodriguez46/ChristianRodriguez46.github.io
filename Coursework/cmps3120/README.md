# CMPS 3120: Algorithm Analysis

Measuring algorithm performance, and the techniques and data structures behind efficient algorithms.

Languages and tools: C, Python.

Each lab starts from the instructor's skeleton program and asks students to write specific functions. Every folder includes `output.txt`, a saved run of the finished program. Labs 2, 3 and 9 link against instructor-provided black-box object files (`blackbox*.o`) that are not included here, so those three only compile on the course server.

## Requirements

A C compiler such as `gcc`. The assignment needs Python 3 with NumPy, SciPy and Matplotlib.
