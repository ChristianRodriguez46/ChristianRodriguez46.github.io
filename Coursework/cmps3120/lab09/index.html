CMPS 3120 · Lab 9

Binary search for hidden positions

Finds the positions of 10 hidden 1 bits among 65,536 using only range queries to a black box: an OR query says whether a range holds any of them, and an XOR query says whether it holds an odd number. A queue of intervals and binary search locate them one at a time, and the saved run finds all 10 with 85 OR and 74 XOR queries.

View code on GitHubREADME

What I did

  • Started from the instructor's skeleton, which has the interval queue and binsearch, and filled in the marked lines in findpos, including the swap in the bubble sort that puts the 10 positions in order.
  • Linked against the instructor's black-box object file (not included), which provides registerme, rangequery and verifysoln.
  • Saved a run in output.txt where all 10 positions are verified.

How to build and run

From the folder with the code:

gcc -o lab9 asgn9.c blackboxA.o  # blackboxA.o is from the course server
./lab9

Requires: A C compiler such as gcc. The assignment needs Python 3 with NumPy, SciPy and Matplotlib.

Links against an instructor-provided object file that is not included here, so this lab only builds on the course server. output.txt shows a complete run.
