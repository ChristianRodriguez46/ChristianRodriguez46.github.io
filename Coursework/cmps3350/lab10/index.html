CMPS 3350 · Lab 10

Word filtering challenge

A word-filter challenge over the instructor's dictionary: print every word that has exactly one letter that is not a vowel, wrapped at 80 columns, then report the count and the longest such word.

View code on GitHubREADME

What I did

  • Wrote countVowels to count the vowels in a C string and used it to find words with exactly one non-vowel letter.
  • Wrapped the output at 80 columns by tracking the line length as words are printed.
  • Tracked the total and the longest matching word with strlen and strcpy.

What I used

  • C++
  • File input
  • C strings
  • Text formatting

Concepts:

  • File input
  • C-string processing

Libraries

C++ standard library: cstring, fstream, iostream.

How to build and run

From the folder with the code:

make
./laba3

Requires: Linux with g++. The graphics labs and the casino game also need X11 and OpenGL (sudo apt install libx11-dev libgl1-mesa-dev libglu1-mesa-dev on Ubuntu). Every folder has a Makefile, so make builds everything in it.

Both programs read the instructor's dictionary file at a path on the course server. To run them elsewhere, change fname near the top of the file to any word list.
