CMPS 3350 · Lab 9

Random numbers and Monte Carlo

Three small programs about random numbers. Two use ten million trials to estimate probabilities of lottery-style patterns, and the third prints a grid of random digits and adds the columns with carries, like long addition.

View code on GitHubREADME

What I did

  • Wrote montecarlo.cpp, which sorts three draws from 1 to 39 with three swaps and counts runs of consecutive numbers that fall in the same group (1-15, 16-30 or 31-39).
  • Wrote vrlab9.cpp, which reads the row and column counts from the command line, keeps column sums in a new[] array and carries from right to left.
  • Used rand.cpp to estimate how often the 5th and 6th of ten draws are both 6 while the 4th is not.

What I used

  • C++
  • Random numbers
  • Monte Carlo simulation
  • Command-line arguments
  • Dynamic arrays

Concepts:

  • Random number generation

Libraries

C++ standard library: cstdlib, ctime, iostream.

How to build and run

From the folder with the code:

make
./montecarlo
./lab9 4 6

Requires: Linux with g++. The graphics labs and the casino game also need X11 and OpenGL (sudo apt install libx11-dev libgl1-mesa-dev libglu1-mesa-dev on Ubuntu). Every folder has a Makefile, so make builds everything in it.
