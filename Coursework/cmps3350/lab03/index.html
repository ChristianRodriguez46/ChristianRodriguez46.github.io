CMPS 3350 · Lab 3

HTTPS requests in C++

A C++ client that fetches a web page over HTTPS: it opens a TCP socket, negotiates TLS with OpenSSL, prints the server's certificate subject and then the page. The folder also has a small PHP page that greets you or does arithmetic with a URL parameter.

View code on GitHubREADME

What I did

  • Ported the instructor's C program (lab3-ssl.c) to C++ so it builds with g++ and OpenSSL 3, leaving a comment with the original line at each fix.
  • Fixed MAX_READ_ERRORS with a #define, made the SSL_METHOD pointer const, replaced SSLv23_client_method with TLS_client_method and removed deprecated calls.
  • Wrote lab3.php, which reads param from the query string and prints a greeting for hello or param*3+4 otherwise.

How to build and run

From the folder with the code:

sudo apt install libssl-dev  # once
make
./lab3 www.example.com index.html

Requires: Linux with g++. The graphics labs and the casino game also need X11 and OpenGL (sudo apt install libx11-dev libgl1-mesa-dev libglu1-mesa-dev on Ubuntu). Every folder has a Makefile, so make builds everything in it.
