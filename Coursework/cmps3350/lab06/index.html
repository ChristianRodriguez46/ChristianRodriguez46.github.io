CMPS 3350 · Lab 6

Waterfall particle simulation

A particle demo of the Waterfall Model: five labeled boxes (Requirements, Design, Coding, Testing, Maintenance) step down the window, and water particles poured from the mouse bounce and slide from one box to the next under gravity.

View code on GitHubREADME

What I did

  • Added five boxes in init_box, sized and placed as fractions of the window so they are laid out again when the window is resized.
  • Spawned particles at the pointer on every mouse move and click, up to 400 at a time.
  • Wrote the collision response in physics: a particle bounces with 60% of its speed and gets a push to the right so it slides off the box.
  • Labeled each box with the instructor's font library (ggprint16).

  • OpenGL
  • X11

How to build and run

From the folder with the code:

make
./waterlab6

Requires: Linux with g++. The graphics labs and the casino game also need X11 and OpenGL (sudo apt install libx11-dev libgl1-mesa-dev libglu1-mesa-dev on Ubuntu). Every folder has a Makefile, so make builds everything in it.

This program opens an X11 window with OpenGL graphics

It needs an X server on the computer you are looking at. On Linux that is already part of the desktop. On a Mac or a Windows PC, or when the program runs on another machine over SSH, see Setting up X11 for what to install and how to check it works.
