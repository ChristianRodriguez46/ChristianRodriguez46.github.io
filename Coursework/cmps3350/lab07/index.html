CMPS 3350 · Lab 7

Days between dates

A Date class that counts the days between two dates by stepping forward one day at a time. The increment operator handles month ends, year ends and leap years, and the program accepts dates in either order.

View code on GitHubREADME

What I did

  • Started from the instructor's skeleton, whose twoDates and daysBetweenDates are marked "Do not modify".
  • Wrote the prefix operator++ with the leap-year rule (divisible by 4, except century years not divisible by 400) and month and year rollover.
  • Compared the two dates in main so the earlier one is always passed first, which fixes the backward test case.
  • Added a command-line mode: with two dates it prints their difference, otherwise it runs the built-in test dates and counts errors.

How to build and run

From the folder with the code:

make
./lab7 01/15/2024 03/01/2025
./lab7  # run the built-in tests

Requires: Linux with g++. The graphics labs and the casino game also need X11 and OpenGL (sudo apt install libx11-dev libgl1-mesa-dev libglu1-mesa-dev on Ubuntu). Every folder has a Makefile, so make builds everything in it.
