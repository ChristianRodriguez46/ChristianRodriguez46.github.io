CMPS 3350 · Lab 1

OpenGL bouncing box

The instructor's OpenGL and X11 starter program: a window with a box that slides back and forth, reversing at each edge. A second version shifts the box's color after each bounce based on how quickly the bounces come.

View code on GitHubREADME

What I did

  • Started from the instructor's sample (lab1.cpp) and changed its background color.
  • Wrote test.cpp, which times each wall collision with clock() and blends the box toward a new color, printing the timing and color values every frame.
  • Wrote waitlist.cpp, a one-line warm-up program, and a Makefile with a target for each program.

What I used

  • C++
  • OpenGL
  • X11
  • Makefiles

Concepts:

How to build and run

From the folder with the code:

make
./lab1

Requires: Linux with g++. The graphics labs and the casino game also need X11 and OpenGL (sudo apt install libx11-dev libgl1-mesa-dev libglu1-mesa-dev on Ubuntu). Every folder has a Makefile, so make builds everything in it.

This program opens an X11 window with OpenGL graphics

It needs an X server on the computer you are looking at. On Linux that is already part of the desktop. On a Mac or a Windows PC, or when the program runs on another machine over SSH, see Setting up X11 for what to install and how to check it works.
