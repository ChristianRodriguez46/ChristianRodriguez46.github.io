CMPS 3350 · Lab 2

Keyboard-controlled animation

An extended version of the bouncing box: it now moves diagonally and bounces off all four walls, turns from blue toward red the more often it hits the side walls, and disappears if the window is narrower than the box. W and S speed it up and slow it down.

View code on GitHubREADME

What I did

  • Split the velocity into velX and velY and added top and bottom collision checks in physics.
  • Measured how many frames pass between side-wall bounces and mapped that frequency to the box color.
  • Added W and S key handling in check_keys, clamping the speed at zero.
  • Skipped drawing the box in render when the window is narrower than the box.

How to build and run

From the folder with the code:

make
./lab2

Requires: Linux with g++. The graphics labs and the casino game also need X11 and OpenGL (sudo apt install libx11-dev libgl1-mesa-dev libglu1-mesa-dev on Ubuntu). Every folder has a Makefile, so make builds everything in it.

This program opens an X11 window with OpenGL graphics

It needs an X server on the computer you are looking at. On Linux that is already part of the desktop. On a Mac or a Windows PC, or when the program runs on another machine over SSH, see Setting up X11 for what to install and how to check it works.
