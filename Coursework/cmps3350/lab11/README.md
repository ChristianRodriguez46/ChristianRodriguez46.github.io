# Android app and download page

**CMPS 3350 Software Engineering**, Lab 11

## What it does

- `MainActivity.java` and `activity_main.xml` are a small Android app that responds to button clicks and touch events.
- `lab11.html` is a download page for the app, styled like an app store listing.

## How to run

Open `lab11.html` in a browser, or try the live demo: [https://christianrodriguez46.github.io/Coursework/cmps3350/lab11/lab11.html](https://christianrodriguez46.github.io/Coursework/cmps3350/lab11/lab11.html)

Requires: Android Studio to build the app. The page opens in any browser.

## Concepts

- Android activities
- Event handling
- HTML and CSS
