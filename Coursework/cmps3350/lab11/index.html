CMPS 3350 · Lab 11

Android app and download page

A first Android app and a download page for it. The app shows "Hello World!", replaces it with a name and shows a toast when the button is tapped, and closes on a long downward swipe.

Live demoView code on GitHubREADME

What I did

  • Wrote MainActivity, with a click handler that changes the text and shows a Toast.
  • Overrode onTouchEvent to close the app when a downward swipe covers half the screen height.
  • Laid out the text and button with a ConstraintLayout in activity_main.xml.
  • Wrote lab11.html, an app store style card with a feature list and a download button.

What I used

  • Java
  • Android
  • XML layouts
  • HTML
  • CSS

Concepts:

  • Android activities
  • Event handling
  • HTML and CSS

How to build and run

Open lab11.html in a browser, or use the live demo above.

Requires: Android Studio to build the app. The page opens in any browser.
