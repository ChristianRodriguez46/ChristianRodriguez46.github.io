# CMPS 3350: Software Engineering

Individual labs and a semester game built by a five-person team.

Languages and tools: C++, OpenGL, X11, Team development.

The graphics labs start from the instructor's OpenGL/X11 sample program; each file's header comment lists the original author and what I changed. `libggfonts.a` is the instructor's text-drawing library used by those labs.

## Requirements

Linux with `g++`. The graphics labs and the casino game also need X11 and OpenGL (`sudo apt install libx11-dev libgl1-mesa-dev libglu1-mesa-dev` on Ubuntu). Every folder has a `Makefile`, so `make` builds everything in it.
