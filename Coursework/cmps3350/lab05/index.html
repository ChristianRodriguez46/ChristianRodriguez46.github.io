CMPS 3350 · Lab 5

Unit testing with build flags

One C++ file that builds three ways with preprocessor flags: a production build that runs w on the server, a who build, and a unit-test build that reads a saved listing. Each build sorts the user names and reports how many users have 1, 2, 3 or more logins.

View code on GitHubREADME

What I did

  • Wrote dslab5.cpp, choosing the data source with #ifdef WHO_TEST, #elif defined(UNIT_TEST) and #else.
  • Parsed the user name from each line, sorted the names with bubbleSort and counted logins per user, then built a frequency table of login counts.
  • Wrote testing.cpp to practice the same idea: built with -D UNIT_TEST it checks multiply against a known answer instead of reading input.
  • Wrote a Makefile that builds all five variants.

How to build and run

From the folder with the code:

make
./ulab5 file.txt  # unit-test build reads saved data
./dslab5  # production build runs w on this machine

Requires: Linux with g++. The graphics labs and the casino game also need X11 and OpenGL (sudo apt install libx11-dev libgl1-mesa-dev libglu1-mesa-dev on Ubuntu). Every folder has a Makefile, so make builds everything in it.
