CMPS 3620 · Lab 1

Network diagnostic tools

A write-up on the standard network diagnostic tools, run from the course server: dig for forward, reverse and SOA lookups, ping for round-trip times, traceroute for the route off campus, ss for listening sockets, and telnet to test a remote port.

View code on GitHubREADME

What I did

  • Ran each tool against several hostnames and addresses and saved the output in outputs.txt.
  • Compared a reverse lookup written as an in-addr.arpa name with the plain dotted form, which returns NXDOMAIN and the root zone's SOA record.
  • Explained in lab-writeup.tex what each result shows: the CNAME and authority sections, sub-10 ms pings, hops that do not answer, and why most listening sockets are on port 53.

What I used

  • dig
  • ping
  • traceroute
  • ss

Concepts:

  • DNS
  • ICMP and routing
  • Sockets on a live system

How to build and run

From the folder with the code:

pdflatex lab-writeup.tex

Requires: Linux with gcc. Write-ups in .tex/.ltx build with any LaTeX distribution (pdflatex).
