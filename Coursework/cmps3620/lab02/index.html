CMPS 3620 · Lab 2

TCP client and server

A TCP client and server that take turns. vcrec asks the system for a free port, prints it and waits; vcsend connects to it, and the two trade lines one at a time until either side sends a period.

View code on GitHubREADME

What I did

  • Started from the course's vcrec.c and vcsend.c, which only send from client to server.
  • Added a reply step to the server: after printing each line it reads one from the keyboard and sends it back with send.
  • Added a matching recv to the client, so it prints the reply before prompting again.
  • Handled a period from either side as the signal to close the connection, and a closed socket (recv returning 0) as the end of the session.
  • Recorded a test run between two terminals (lab2.mp4).

How to build and run

From the folder with the code:

make
./vcrec  # prints a port number
./vcsend localhost <port>  # in a second terminal

Requires: Linux with gcc. Write-ups in .tex/.ltx build with any LaTeX distribution (pdflatex).
