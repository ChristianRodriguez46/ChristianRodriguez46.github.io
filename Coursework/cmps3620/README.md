# CMPS 3620: Computer Networks

TCP/IP networking, with labs on sockets, I/O handling, process control and client/server programs.

Languages and tools: C, sockets.

The socket labs build on networking example code by Marc Thomas that the course provides; each lab extends it and answers questions about how it works in a write-up.

## Requirements

Linux with `gcc`. Write-ups in `.tex`/`.ltx` build with any LaTeX distribution (`pdflatex`).
