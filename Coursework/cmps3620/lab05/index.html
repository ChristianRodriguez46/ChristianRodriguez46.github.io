CMPS 3620 · Lab 5

Multi-client server

A server that handles several clients at once. simple_daemon.c accepts connections in a loop and forks a child for each one; the child runs simple_shell.c and passes data between it and the socket through two pipes. The write-up explains how it works.

View code on GitHubREADME

What I did

  • Built the course's daemon and shell and connected to them from several terminals at once.
  • Answered the write-up in Lab write up.md: why each client gets its own process and pipes, why Ctrl-C in a telnet session does not end it, and which signals shut the daemon down cleanly.
  • Traced how the server notices quit: the shell exits, its pipe closes, and read returns 0.
  • Related the design to how sshd forks a process for every login.

How to build and run

From the folder with the code:

make
./s_daemon  # prints a port number
telnet localhost <port>  # in other terminals

Requires: Linux with gcc. Write-ups in .tex/.ltx build with any LaTeX distribution (pdflatex).
