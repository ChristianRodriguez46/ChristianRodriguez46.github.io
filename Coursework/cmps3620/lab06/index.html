CMPS 3620 · Lab 6

Telnet-style shell service

A study of the course's full networking package: a telnet-style shell service (s_daemon and s_sh), a raw-socket telnet client (s_tlnt), and datagram, pipe, session and diagnostic tools. The write-up explains how the shell manages its child processes and how the client draws a text interface.

View code on GitHubREADME

What I did

  • Built s_sh and s_tlnt with the lab's Makefile and ran the shell from the command line.
  • Explained why s_sh watches SIGCLD: its handler calls wait so finished children do not become zombies and the job list stays correct.
  • Described how the built-in commands (cd, history, jobs and others) run inside the shell while everything else goes through fork and exec.
  • Explained how process_esc in s_tlnt turns escape sequences into cursor movement for full-screen programs, and how header.h lets the same code build on Windows and Unix.
