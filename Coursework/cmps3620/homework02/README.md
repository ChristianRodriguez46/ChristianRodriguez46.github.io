# Physical layer homework

**CMPS 3620 Computer Networks**, Homework 2

Read this lab with snapshots and notes on every file: [https://christianrodriguez46.github.io/Coursework/cmps3620/homework02/](https://christianrodriguez46.github.io/Coursework/cmps3620/homework02/)

## What it does

`answer.tex` holds worked solutions to textbook questions on the physical layer, such as maximum data rates over noiseless and noisy channels (Nyquist and Shannon). `questions.txt` lists the assigned problems.

## How to run

From this folder:

```bash
pdflatex answer.tex
```

Requires: Linux with `gcc`. Write-ups in `.tex`/`.ltx` build with any LaTeX distribution (`pdflatex`).

## Concepts

- Nyquist and Shannon limits
- Signal encoding
