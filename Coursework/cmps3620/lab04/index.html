CMPS 3620 · Lab 4

Full-duplex chat with select()

The lab 2 chat made full-duplex. Each side calls select() on both the keyboard and the socket, so either person can type at any time and incoming lines are printed as soon as they arrive.

View code on GitHubREADME

What I did

  • Replaced the take-turns loop in both programs with a select() loop over STDIN_FILENO and the connected socket, rebuilding the fd_set with FD_ZERO and FD_SET each time.
  • Read and printed from the socket when FD_ISSET reports it ready, and sent a typed line when the keyboard is ready.
  • Kept the period as the way to end the chat from either side, and stripped newlines with strcspn.
