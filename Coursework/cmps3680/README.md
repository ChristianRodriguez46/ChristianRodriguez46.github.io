# CMPS 3680: Server-Side Web

Server-side development: web servers, data interchange formats, storage and retrieval with MySQL, and security.

Languages and tools: PHP, MySQL, JavaScript.

These labs ran on the course server, where the database login lived in `config.php`. In this copy the login is replaced with placeholders; put your own MySQL user, password and database name there before running the database labs.

## Requirements

PHP 7.4 or later; labs 5, 6 and the final project also need MySQL (or MariaDB) and the PHP `mysqli` extension. Run each folder with PHP's built-in server: `php -S localhost:8000`.
