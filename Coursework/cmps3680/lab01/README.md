# Client-side form validation

**CMPS 3680 Server-Side Web**, Lab 1

## What it does

A contact form (name, email, phone, major) checked in JavaScript before it submits: empty or badly formatted fields are highlighted, and a valid submission is summarized on the page. `experiment.html` and `script-demo.js` are working copies.

## How to run

Open `lab1.html` in a browser, or try the live demo: [https://christianrodriguez46.github.io/Coursework/cmps3680/lab01/lab1.html](https://christianrodriguez46.github.io/Coursework/cmps3680/lab01/lab1.html)

Requires: PHP 7.4 or later; labs 5, 6 and the final project also need MySQL (or MariaDB) and the PHP `mysqli` extension. Run each folder with PHP's built-in server: `php -S localhost:8000`.
