CMPS 3680 · Lab 1

Client-side form validation

A contact form checked in JavaScript before it submits. Empty required fields, and an email without both @ and ., are outlined in red, and a valid submission reloads the page and summarizes the values it reads back from the query string.

Live demoView code on GitHubREADME

What I did

  • Wrote validateForm, which clears old errors, loops over the required fields (fName, lName, email, comments) and marks empty ones with an error class.
  • Added an email check that requires both @ and . before the form can submit.
  • Read the submitted values back with URLSearchParams in an inline script and wrote a summary into the #output box, skipping the phone and major when they are blank.
  • Styled the form in style.css with two floated columns and a red glow for invalid fields.

What I used

Concepts:

How to build and run

Open lab1.html in a browser, or use the live demo above.

Requires: PHP 7.4 or later; labs 5, 6 and the final project also need MySQL (or MariaDB) and the PHP mysqli extension. Run each folder with PHP's built-in server: php -S localhost:8000.
