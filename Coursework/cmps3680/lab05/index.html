CMPS 3680 · Lab 5

Setting up MySQL

The lab 4 product manager plus its first MySQL code: a sql/ folder that connects with mysqli, creates and drops a product table, and tests the connection. Products are still saved to the JSON file in this lab.

View code on GitHubREADME

What I did

  • Added sql/sqlTools.php with getConnection, which opens a mysqli connection from the login in config.php, and closeConnection.
  • Defined the product table in sql/create.php (internal ID, name, vendor, phone, quantity, last-purchased date and created/updated timestamps) and removed it with sql/drop.php.
  • Checked the database login with sql/test.php, which connects, prints a message and closes.
  • Carried over the lab 4 add and remove pages unchanged.

What I used

  • PHP
  • MySQL
  • mysqli
  • SQL
  • JSON file storage

Concepts:

  • Connecting to MySQL with mysqli
  • Creating tables

Libraries

Uses mysqli (PHP MySQL extension).

How to build and run

From the folder with the code:

  # one time: create a MySQL database and user, then put them in config.php
php sql/create.php  # creates the table
php -S localhost:8000

Requires: PHP 7.4 or later; labs 5, 6 and the final project also need MySQL (or MariaDB) and the PHP mysqli extension. Run each folder with PHP's built-in server: php -S localhost:8000.
