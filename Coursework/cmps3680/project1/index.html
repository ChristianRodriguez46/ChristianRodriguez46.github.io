CMPS 3680 · Project 1

Quiz app

A quiz app driven by JSON files. takeQuiz.php?q=geo (or mov, mus) builds a dropdown for each question from quizzes/<name>_quiz.json and loads that quiz's own stylesheet, and gradeQuiz.php marks each answer correct or incorrect and shows the right one.

View code on GitHubREADME

What I did

  • Wrote getQuiz in quizTools.php, which loads and decodes a quiz file and stops with a message if the file is missing or not valid JSON.
  • Checked the q parameter against /^[a-z]{3}$/ before building the file name, so it cannot point outside quizzes/.
  • Generated each question's <select> in questionHTML with an empty first option and required, so every question needs an answer.
  • Graded the posted answers in gradeQuiz.php, looking each one up with getQuestion and rejecting the form if any answer is empty.
  • Wrote three five-question quizzes (geography, movies and music) and gave each one its own stylesheet.

How to build and run

From the folder with the code:

php -S localhost:8000
  # open http://localhost:8000/takeQuiz.php?q=geo

Requires: PHP 7.4 or later; labs 5, 6 and the final project also need MySQL (or MariaDB) and the PHP mysqli extension. Run each folder with PHP's built-in server: php -S localhost:8000.
