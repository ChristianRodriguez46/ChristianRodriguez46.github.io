CMPS 3680 · Lab 4

Product manager with a JSON file

A product manager that stores products in data/products.json. The add form is checked on the server with regular expressions and comes back with a message next to each bad field, and the remove page can clear the whole list.

View code on GitHubREADME

What I did

  • Started from the instructor's skeleton (productTools.php, the ID check and the TODO markers) and added the product name, vendor, phone, quantity and last-purchased fields to add.php.
  • Wrote the validators in validate.php (validProductName, validVendor, validPnum, validQuantity) with preg_match.
  • Kept the submitted values in the form after an error and printed each message next to its field.
  • Built remove.php with a Dump button that empties the product file and a remove-by-ID form.
  • Listed every saved product under both forms and styled the pages with a fixed navigation bar.

How to build and run

From the folder with the code:

php -S localhost:8000
  # open http://localhost:8000/add.php

Requires: PHP 7.4 or later; labs 5, 6 and the final project also need MySQL (or MariaDB) and the PHP mysqli extension. Run each folder with PHP's built-in server: php -S localhost:8000.

productTools.php looks products up by a lowercase id key while add.php saves them as ID, so duplicate IDs are not caught and removing by ID reports "Product is not found". Lab 6 uses id throughout.
