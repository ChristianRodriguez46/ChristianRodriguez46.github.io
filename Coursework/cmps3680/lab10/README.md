# Calling a web API with jQuery

**CMPS 3680 Server-Side Web**, Lab 10

## What it does

`lab10.html` sends JSON requests with jQuery's `$.ajax` to the instructor's API for three actions (a greeting, adding two numbers, and a GIF search) and shows each response or error on the page.

## How to run

Open `lab10.html` in a browser, or try the live demo: [https://christianrodriguez46.github.io/Coursework/cmps3680/lab10/lab10.html](https://christianrodriguez46.github.io/Coursework/cmps3680/lab10/lab10.html)

Requires: PHP 7.4 or later; labs 5, 6 and the final project also need MySQL (or MariaDB) and the PHP `mysqli` extension. Run each folder with PHP's built-in server: `php -S localhost:8000`.

## Note

It calls the instructor's server at paul.cs3680.com, so it only works while that server is online.
