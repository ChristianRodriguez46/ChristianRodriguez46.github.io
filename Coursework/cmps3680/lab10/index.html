CMPS 3680 · Lab 10

Calling a web API with jQuery

A page that calls the instructor's JSON-RPC style web API with jQuery. Three small forms send a greeting, an addition and a GIF search as JSON POST requests, and each reply, or the server's error message, is written into the page.

Live demoView code on GitHubREADME

What I did

  • Started from the instructor's page, which marks the three sections to connect, and wrote script.js.
  • Wrote sendRequest, which posts a request object as JSON with $.ajax and hands the reply to displayResult or displayError.
  • Built the request objects (method, params, id and jsonrpc: "2.0") in the three button handlers.
  • Matched each reply to its section by id in displayResult, setting the text for the greeting and the sum and the image src for the GIF.
  • Showed the error message from the response in a hidden #error box that displayError reveals.

How to build and run

Open lab10.html in a browser, or use the live demo above.

Requires: PHP 7.4 or later; labs 5, 6 and the final project also need MySQL (or MariaDB) and the PHP mysqli extension. Run each folder with PHP's built-in server: php -S localhost:8000.

It calls the instructor's server at paul.cs3680.com, so it only works while that server is online.
