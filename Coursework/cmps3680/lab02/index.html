CMPS 3680 · Lab 2

PHP basics

First PHP pages. lab2.php builds a 10 by 10 multiplication table with a PHP function and prints a text file into a scrolling box, and two short scripts try out output, loops and error reporting.

View code on GitHubREADME

What I did

  • Wrote generateMultiplicationTable, which echoes the table rows and cells with two nested loops.
  • Read lorem.txt with file_get_contents and kept its line breaks with nl2br.
  • Used define constants for the page title and stylesheet, and logged a message with error_log when a variable is not set.
  • Ran pratice.php from the command line to try echo and a for loop, and used test.php to see the warning for an undefined variable.

How to build and run

From the folder with the code:

php -S localhost:8000
  # open http://localhost:8000/lab2.php

Requires: PHP 7.4 or later; labs 5, 6 and the final project also need MySQL (or MariaDB) and the PHP mysqli extension. Run each folder with PHP's built-in server: php -S localhost:8000.
