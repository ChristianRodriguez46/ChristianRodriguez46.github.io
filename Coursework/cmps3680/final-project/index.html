CMPS 3680 · Final project

Car detailing site with PHP and MySQL

Wise Choice Detailing, a site for a mobile car detailing business, rebuilt from the CMPS 2680 front end with a PHP and MySQL backend. Customers book an appointment that the server validates and saves under a random 10-character order number, and the contact form checks that order number against the database before emailing the message. A sign-up and sign-in page with hashed passwords was started but not finished.

View code on GitHubREADME

What I did

  • Wrote booking.php, which posts the appointment form back to itself, checks every field with the functions in validate.php (validFname, validEmail, validZip, validPnum, validYear and others) and requires a package or at least one service through validateOrder.
  • Saved bookings in sql/sqlTools.php: addOrder makes the order number with random_int in generateRandomString, stores the exterior and interior service lists as JSON columns and inserts the row with a prepared statement. getUniqueOrder reads it back and printUniqueOrder shows the confirmation under the form.
  • Wrote the contact handler contact.php, with validators in scripts/mail.php: it cleans each field with cleanData, checks the email, phone and order number formats, confirms the order exists with checkOrderNumber and sends the message with mail().
  • Started accounts in login.php: one form switches between sign-up and sign-in with jQuery, sign-up hashes the password with password_hash, and sign-in is written to check it with password_verify and store the user in $_SESSION. The users table is defined in sql/create.php.
  • Added queries for pages still to come, such as getOrder (all appointments, marked for an admin view), getUserOrder (one customer's appointments), removeOrder and dumpOrders, and tried them in sql/test.php.
  • Reworked the CMPS 2680 pages: the links now go to booking.php, the scripts moved into scripts/, and the gallery became 11 before-and-after photo sliders driven by a range input and a CSS --position variable.

How to build and run

From the folder with the code:

  # one time: create a MySQL database and user, then put them in config.php
php sql/create.php  # creates the table
php -S localhost:8000
  # open http://localhost:8000/home.html

Requires: PHP 7.4 or later; labs 5, 6 and the final project also need MySQL (or MariaDB) and the PHP mysqli extension. Run each folder with PHP's built-in server: php -S localhost:8000.

The database login for this project is in sql/config.php. sql/create.php defines both the appointments and users tables. The appointments statement is commented out because that table already existed on the course server; uncomment it on a fresh database. The contact form needs a mail server to actually send email.
