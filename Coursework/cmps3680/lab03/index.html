CMPS 3680 · Lab 3

Templated product catalog

A storefront page for "Juan's Services" put together from header.php and footer.php includes. The products are read from products.json, sorted by quantity with uasort and printed as cards.

View code on GitHubREADME

What I did

  • Split the page into header.php and footer.php and assembled it in home.php with require_once.
  • Decoded products.json with json_decode and sorted the products by quantity with uasort and the <=> operator.
  • Printed each product as a card in products.php, then wrote eproducts.php, which builds the same cards with heredoc strings and is the version home.php uses.
  • Laid out the cards with flexbox in style.css.

What I used

  • PHP
  • JSON
  • Includes
  • Heredoc strings
  • Sorting
  • CSS flexbox

Concepts:

  • PHP includes
  • Reading JSON

How to build and run

From the folder with the code:

php -S localhost:8000
  # open http://localhost:8000/home.php

Requires: PHP 7.4 or later; labs 5, 6 and the final project also need MySQL (or MariaDB) and the PHP mysqli extension. Run each folder with PHP's built-in server: php -S localhost:8000.
