CMPS 3680 · Lab 6

Product manager with MySQL

The product manager moved from the JSON file to MySQL. Adding, listing, removing and clearing products go through sql/sqlTools.php with prepared statements, and product IDs are kept unique by a lookup before each insert and a UNIQUE column.

View code on GitHubREADME

What I did

  • Rewrote the storage functions in sql/sqlTools.php (addProduct, removeProduct, dumpProducts, getProducts, uniqueID) on top of mysqli, with prepared statements for every query that takes user input.
  • Switched add.php and remove.php to the new functions and renamed the form keys to lowercase id, vendor and quantity.
  • Made internalId UNIQUE and renamed name to productName in the CREATE TABLE statement.
  • Loosened validProductName to allow spaces, apostrophes and hyphens.
  • Tested the queries from the command line with sql/test.php, which lists the products and checks two IDs with uniqueID.

How to build and run

From the folder with the code:

  # one time: create a MySQL database and user, then put them in config.php
php sql/create.php  # creates the table
php -S localhost:8000
  # open http://localhost:8000/add.php

Requires: PHP 7.4 or later; labs 5, 6 and the final project also need MySQL (or MariaDB) and the PHP mysqli extension. Run each folder with PHP's built-in server: php -S localhost:8000.
