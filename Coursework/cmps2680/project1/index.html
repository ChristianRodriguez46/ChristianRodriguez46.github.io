CMPS 2680 · Project 1

Hobbies site

A three-page site about two hobbies, watching hockey and playing video games. The home page introduces both, and each hobby page has illustrated sections on history, variations, popularity, controversies and fun facts, next to a sidebar of links and embedded videos.

Live demoView code on GitHubREADME

What I did

  • Wrote three pages that share a fixed navigation bar, with the current page highlighted through an #active link.
  • Laid out each hobby page as a 70% content column and a 29% sidebar with floats, and cleared them with clear: left on the footer.
  • Floated pictures beside the text and placed the AHL and ECHL logos side by side in a flex row.
  • Embedded YouTube videos in the sidebars, and an Instagram post on the video games page, with <iframe>.
  • Used a flex column for the content panels so they grow with their text instead of a fixed height.

What I used

  • HTML
  • CSS
  • Floats
  • Flexbox
  • Fixed positioning
  • Iframes

Concepts:

  • Page structure
  • Styling with CSS

How to build and run

Open home.html in a browser, or use the live demo above.

Requires: Any modern web browser. No server or build step is needed.
