# Hobbies site

**CMPS 2680 Client-Side Web**, Project 1

## What it does

A three-page site about my hobbies: a home page plus pages on hockey and video games, each with images and links.

## How to run

Open `home.html` in a browser, or try the live demo: [https://christianrodriguez46.github.io/Coursework/cmps2680/project1/home.html](https://christianrodriguez46.github.io/Coursework/cmps2680/project1/home.html)

Requires: Any modern web browser. No server or build step is needed.
