First PHP script

A short PHP script that stores a string in a variable and prints it with echo, using double-quoted string interpolation. It was the course's first look at server-side code.

View code on GitHubREADME

What I did

  • Assigned $txt = "PHP" and printed I love $txt!, letting PHP fill in the variable inside double quotes.
  • Wrapped the code in <?php ... ?> tags so the file can run from the command line or be served as a page.
  • Ran it with the command-line interpreter (php example.php).
