# Number guessing game

**CMPS 2680 Client-Side Web**, Lab 6

## What it does

**New Game** picks a random number from -10 to 10 and shows three clues: whether it is between -5 and 5, even or odd, and positive or negative. **Guess Number** asks for one guess and tells you whether you won.

## How to run

Open `guess.html` in a browser, or try the live demo: [https://christianrodriguez46.github.io/Coursework/cmps2680/lab06/guess.html](https://christianrodriguez46.github.io/Coursework/cmps2680/lab06/guess.html)

Requires: Any modern web browser. No server or build step is needed.

## Concepts

- Event listeners
- Random numbers
- Updating the DOM
