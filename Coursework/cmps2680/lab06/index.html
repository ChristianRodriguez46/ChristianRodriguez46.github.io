CMPS 2680 · Lab 6

Number guessing game

A guessing game in the browser. New Game picks a random whole number from -10 to 9 and prints clues about it (range, even or odd, sign), and Guess Number asks for a guess in a prompt dialog and says whether it matched.

Live demoView code on GitHubREADME

What I did

  • Started from the instructor's skeleton (the genRandom helper and a page-load listener with TODO comments) and wrote startGame and playGame.
  • Built the clue text in startGame from three if/else checks (the -5 to 5 range, number % 2 and the sign) and wrote it into the #clues box with innerHTML.
  • Read the guess with window.prompt in playGame, announced the result with window.alert and reset the number so each game allows one guess.
  • Stopped guesses before a game starts with an alert telling the player to click New Game.
  • Attached both handlers to the buttons with addEventListener once the page loads.

How to build and run

Open guess.html in a browser, or use the live demo above.

Requires: Any modern web browser. No server or build step is needed.
