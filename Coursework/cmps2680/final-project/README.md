# Car detailing site

**CMPS 2680 Client-Side Web**, Final project

## What it does

A five-page site for a car detailing business, built with Bootstrap:

- **Home** with a rotating image board (`home.js`).
- **Services** listing packages and individual interior and exterior services.
- **Booking**, a validated form for contact details, car, date and services; after submitting, the page shows a summary of the appointment (`script.js`).
- **Gallery** of before-and-after photos that open enlarged (`gallery.js`).
- **Contact**, a contact form (`contact.js`).

`experiments/` holds drafts of the booking page.

## How to run

Open `home.html` in a browser, or try the live demo: [https://christianrodriguez46.github.io/Coursework/cmps2680/final-project/home.html](https://christianrodriguez46.github.io/Coursework/cmps2680/final-project/home.html)

Requires: Any modern web browser. No server or build step is needed.
