CMPS 2680 · Final project

Car detailing site

A five-page Bootstrap site for a mobile car detailing business: home, services, booking, gallery and contact. The booking form pairs Bootstrap's validation styles with its own check that a package or service is chosen, then shows an appointment summary read back from the URL.

Live demoView code on GitHubREADME

What I did

  • Built five pages that share a dark Bootstrap navbar and footer, with one stylesheet per page in styles/.
  • Wrote home.js, which cycles the home page's image board through three photos every six seconds with setTimeout.
  • Wrote the booking logic in script.js: validateForm blocks submission until a package or individual service is picked, and on reload displayPersonalInfo, formatDateTime and displayCheckedValues turn the query string into an appointment summary.
  • Added Bootstrap's starter validation snippet so empty required fields show their invalid-feedback messages after a failed submit.
  • Used jQuery in gallery.js to open a before or after photo in a full-screen overlay (fadeIn and fadeOut), and in contact.js to check that all three fields are filled before showing a thank-you message.
  • Laid out the price list on service.html as striped dark Bootstrap tables for the Bronze, Silver and Gold packages and the individual services.
