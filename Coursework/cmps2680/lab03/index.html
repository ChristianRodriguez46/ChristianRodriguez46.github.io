CMPS 2680 · Lab 3

Small business site

A three-page site for a made-up home-repair business called QuickFix Solutions: a home page, a services page with prices and a contact page. All three share one stylesheet with a sticky navigation bar, rounded content panels and floated images.

Live demoView code on GitHubREADME

What I did

  • Wrote home.html, services.html and contact.html with the same header, navigation list and footer.
  • Styled the navigation list in style.css as a horizontal bar: floated items, position: sticky, and :hover, :visited and :active link colors.
  • Laid out each service as a rounded panel with a floated thumbnail (object-fit: cover), a description and a price in small caps.
  • Gave the content panels a border, border-radius and box-shadow, and centered the contact details in a narrower panel.

What I used

  • HTML
  • CSS
  • Multi-page sites
  • Floats
  • Sticky positioning
  • Pseudo-classes

Concepts:

  • Multi-page sites
  • Shared stylesheets

How to build and run

Open home.html in a browser, or use the live demo above.

Requires: Any modern web browser. No server or build step is needed.
