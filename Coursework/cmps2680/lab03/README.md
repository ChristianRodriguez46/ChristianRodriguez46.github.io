# Small business site

**CMPS 2680 Client-Side Web**, Lab 3

## What it does

A three-page site for a fictional home-repair business: a home page, a services page and a contact page, styled with one shared `style.css`.

## How to run

Open `home.html` in a browser, or try the live demo: [https://christianrodriguez46.github.io/Coursework/cmps2680/lab03/home.html](https://christianrodriguez46.github.io/Coursework/cmps2680/lab03/home.html)

Requires: Any modern web browser. No server or build step is needed.

- Multi-page sites
- Shared stylesheets
