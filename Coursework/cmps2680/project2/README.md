# To-do list

**CMPS 2680 Client-Side Web**, Project 2

## What it does

Type a task and press **Add** (or Enter) to add it to the list. Click a task to remove it.

## How to run

Open `todo.html` in a browser, or try the live demo: [https://christianrodriguez46.github.io/Coursework/cmps2680/project2/todo.html](https://christianrodriguez46.github.io/Coursework/cmps2680/project2/todo.html)

Requires: Any modern web browser. No server or build step is needed.

## Concepts

- Creating and removing elements
- Keyboard and click events
