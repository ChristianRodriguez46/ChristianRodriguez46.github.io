CMPS 2680 · Project 2

To-do list

A to-do list. Type a task and press ADD or Enter to add it, then click a task to remove it. Hovering over a task strikes it through in red as a hint.

Live demoView code on GitHubREADME

What I did

  • Wrote addTodo, which creates a div.listItem with the typed text, appends it to #list and clears the input.
  • Called addTodo from both the ADD button's click event and a keypress listener that checks for event.key == "Enter".
  • Removed a task on click by registering the element's own remove method as its listener.
  • Styled the hover state with text-decoration: line-through red and a pointer cursor so it is clear that a click deletes the task.

What I used

  • JavaScript
  • HTML
  • CSS
  • Creating and removing elements
  • Keyboard and click events

Concepts:

  • Creating and removing elements
  • Keyboard and click events

How to build and run

Open todo.html in a browser, or use the live demo above.

Requires: Any modern web browser. No server or build step is needed.
