# Live multiples

**CMPS 2680 Client-Side Web**, Lab 7

## What it does

Type a number and the page lists its multiples as you type (`keyup` event).

## How to run

Open `lab7.html` in a browser, or try the live demo: [https://christianrodriguez46.github.io/Coursework/cmps2680/lab07/lab7.html](https://christianrodriguez46.github.io/Coursework/cmps2680/lab07/lab7.html)

Requires: Any modern web browser. No server or build step is needed.

## Concepts

- Keyboard events
- Generating HTML from JavaScript
