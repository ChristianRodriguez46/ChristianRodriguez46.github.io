CMPS 2680 · Lab 7

Live multiples

Type a number and the page lists its first twelve multiples as you type. Anything that is not a number shows an error message instead.

Live demoView code on GitHubREADME

What I did

  • Attached generateMultiples to the text box's keyup event once the page loads.
  • Checked the value with isNaN and an empty-string test and showed PLEASE ENTER A VALID NUMBER when it fails.
  • Built the list in a loop over the multipliers 1 to 12, alternating the classes a and b so the boxes switch between green and blue.
  • Wrote the generated HTML into #multiples with a single innerHTML assignment.

What I used

  • JavaScript
  • HTML
  • CSS
  • Keyboard events
  • Loops
  • Generating HTML

Concepts:

  • Keyboard events
  • Generating HTML from JavaScript

How to build and run

Open lab7.html in a browser, or use the live demo above.

Requires: Any modern web browser. No server or build step is needed.
