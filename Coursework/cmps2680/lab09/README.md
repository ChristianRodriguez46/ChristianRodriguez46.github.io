# Form input and output

**CMPS 2680 Client-Side Web**, Lab 9

## What it does

A form for first name, last name, email and birthday. After submitting, `script.js` reads the values from the URL and prints them under **Output**.

## How to run

Open `lab9.html` in a browser, or try the live demo: [https://christianrodriguez46.github.io/Coursework/cmps2680/lab09/lab9.html](https://christianrodriguez46.github.io/Coursework/cmps2680/lab09/lab9.html)

Requires: Any modern web browser. No server or build step is needed.

## Concepts

- HTML forms
- Validation attributes
- Reading query parameters
