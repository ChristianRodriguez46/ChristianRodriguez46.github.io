CMPS 2680 · Lab 9

Form input and output

A form for first name, last name, email and birthday that submits to its own page. When the page reloads, script.js reads the values back out of the query string and prints them under OUTPUT.

Live demoView code on GitHubREADME

What I did

  • Built the form with labeled text, email and date inputs and made the email and birthday required.
  • Read window.location.search on page load and pulled each field out with URLSearchParams.get.
  • Wrote the values into the #Output box, which shows PLEASE COMPLETE THE FORM until the form is submitted.
  • Styled the form as a translucent blue card with a glowing box-shadow over an animated GIF background.

Concepts:

How to build and run

Open lab9.html in a browser, or use the live demo above.

Requires: Any modern web browser. No server or build step is needed.
