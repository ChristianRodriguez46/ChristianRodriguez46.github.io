CMPS 2680 · Lab 10

Business site with Bootstrap

The QuickFix Solutions site from lab 3 rebuilt with Bootstrap 5. The pages get a Bootstrap navbar whose links fold behind a menu button, Bootstrap containers and rounded images, while a reworked copy of the lab 3 stylesheet keeps the panels and colors.

Live demoView code on GitHubREADME

What I did

  • Loaded Bootstrap 5.2.3 CSS and JavaScript from the jsDelivr CDN and added the viewport meta tag.
  • Replaced the hand-made navigation list with a Bootstrap navbar that collapses behind a toggler button (data-bs-toggle="collapse") and marks the current page with active.
  • Wrapped the content in container and container-fluid divs and rounded the photos with rounded and rounded-circle, overriding the circle to a 36% radius in style.css.
  • Reworked style.css from lab 3: min-width on the containers, a flex column for the contact panel and a custom navbar color.
