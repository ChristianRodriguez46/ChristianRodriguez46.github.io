CMPS 2680 · Lab 2

Linked pages and images

Three linked pages: an index, an about-me page and an image page. The about page practices text-formatting tags and an ordered list, and the image page mixes local and remote images, one of them wrapped in a link.

Live demoView code on GitHubREADME

What I did

  • Built lab2.html as an index with an unordered list of relative links to the other two pages and one external link.
  • Wrote about.html with three heading levels, an ordered list and two paragraphs marked up with <b>, <i>, <strong>, <del>, <ins>, <mark> and <small>.
  • Placed three images on images.html (an animated GIF loaded from a remote URL, a local GIF and a JPEG) and sized them with the width attribute.
  • Turned the csub.png logo into a link and gave it alt text.

What I used

  • HTML
  • Links
  • Images
  • Lists
  • Text formatting tags

Concepts:

  • Links between pages
  • Images
  • Headings and lists

How to build and run

Open lab2.html in a browser, or use the live demo above.

Requires: Any modern web browser. No server or build step is needed.
