# Linked pages and images

**CMPS 2680 Client-Side Web**, Lab 2

## What it does

Three linked pages: `lab2.html` (index), `about.html` (an about-me page) and `images.html` (an image gallery).

## How to run

Open `lab2.html` in a browser, or try the live demo: [https://christianrodriguez46.github.io/Coursework/cmps2680/lab02/lab2.html](https://christianrodriguez46.github.io/Coursework/cmps2680/lab02/lab2.html)

Requires: Any modern web browser. No server or build step is needed.

## Concepts

- Links between pages
- Images
- Headings and lists
