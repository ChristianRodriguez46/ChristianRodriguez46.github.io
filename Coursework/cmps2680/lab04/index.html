CMPS 2680 · Lab 4

CSS box layout

One page that fits four 300-pixel boxes into a two-by-two square inside a glowing container. Each box exercises a different part of the CSS box model, so the grid only lines up if border and padding are counted in each box's size.

Live demoView code on GitHubREADME

What I did

  • Sized #box2 (260 pixels plus a 20-pixel border) and #box3 (270 pixels plus 15-pixel padding) so both come back to 300 pixels and the grid stays exact.
  • Floated all four boxes left inside a 600-pixel #container so they wrap into two rows.
  • Added a light-green box-shadow to the container, rounded corners on the yellow box and contrasting text colors in the red and purple boxes.
  • Offset the container with a 650-pixel margin on a black page.

What I used

How to build and run

Open lab4.html in a browser, or use the live demo above.

Requires: Any modern web browser. No server or build step is needed.
