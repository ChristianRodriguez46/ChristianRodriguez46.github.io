# Deck of cards

**CMPS 2680 Client-Side Web**, Lab 8

## What it does

`poker.js` defines `Card` and `Deck` objects. **Shuffle** builds and shuffles a 52-card deck; clicking the deck draws cards into your hand, using the card images in `cards/`.

## How to run

Open `lab8.html` in a browser, or try the live demo: [https://christianrodriguez46.github.io/Coursework/cmps2680/lab08/lab8.html](https://christianrodriguez46.github.io/Coursework/cmps2680/lab08/lab8.html)

Requires: Any modern web browser. No server or build step is needed.

## Concepts

- JavaScript objects and constructors
- Arrays
- Shuffling
