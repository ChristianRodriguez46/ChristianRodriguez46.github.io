CMPS 2680 · Lab 8

Deck of cards

A deck of cards in the browser. The page shuffles a 52-card deck when it loads, each click on the deck deals the top card face up onto a green table, and an empty deck turns red and lights up the SHUFFLE button.

Live demoView code on GitHubREADME

What I did

  • Started from the instructor's skeleton, whose numbered TODO comments outline each step and which supplied CardElement, and wrote the bodies of shuffle, drawCard and the page-load setup in script.js.
  • Used the Card and Deck constructors in poker.js: a Deck builds all 52 cards from suit and type arrays and shuffles them with sort.
  • Dealt cards by popping from deck.cards and appending a CardElement (the card image and a caption such as "The Ace of spades") to #playerCards.
  • Handled an empty deck by switching the deck image to Red.png and adding the on class to the SHUFFLE button.

How to build and run

Open lab8.html in a browser, or use the live demo above.

Requires: Any modern web browser. No server or build step is needed.
