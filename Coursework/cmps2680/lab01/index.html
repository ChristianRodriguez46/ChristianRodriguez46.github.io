CMPS 2680 · Lab 1

First HTML page

A first HTML page with one heading and one paragraph, written at the start of the course. It sets up the parts every later page reuses: the doctype, the lang attribute, the character set and the title.

Live demoView code on GitHubREADME

What I did

  • Wrote the HTML5 skeleton by hand: <!DOCTYPE html>, <html lang='en'>, <head> and <body>.
  • Set the character encoding with <meta charset='utf-8'> and gave the tab a <title>.
  • Added an <h1> heading with the lab name and a paragraph introducing the page.

What I used

  • HTML
  • Document structure
  • Headings
  • Paragraphs

Concepts:

  • HTML document structure

How to build and run

Open lab1.html in a browser, or use the live demo above.

Requires: Any modern web browser. No server or build step is needed.
