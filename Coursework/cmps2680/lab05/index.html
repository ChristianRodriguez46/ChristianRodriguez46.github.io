CMPS 2680 · Lab 5

Photo gallery

A photo gallery with four animal thumbnails in a row and a large viewer below them. Clicking a thumbnail calls showImage, which points the viewer at the full-size picture.

Live demoView code on GitHubREADME

What I did

  • Wrote showImage(image) in script.js, which builds the path ./images/<name>.png and sets it as the src of the #fullview image.
  • Attached the function to each thumbnail with an inline onclick handler.
  • Laid out the thumbnails in a centered row with flexbox and styled each one as a card with a caption.
  • Showed a placeholder image (click.png) in the viewer until a thumbnail is clicked.

What I used

  • JavaScript
  • HTML
  • CSS
  • DOM manipulation
  • Click handlers
  • Flexbox

Concepts:

  • DOM manipulation
  • Click handlers
  • Flexbox

How to build and run

Open gallery.html in a browser, or use the live demo above.

Requires: Any modern web browser. No server or build step is needed.
