# Photo gallery

**CMPS 2680 Client-Side Web**, Lab 5

## What it does

A gallery of thumbnails; clicking one shows the full-size image in a large viewer (`script.js`, `showImage`).

## How to run

Open `gallery.html` in a browser, or try the live demo: [https://christianrodriguez46.github.io/Coursework/cmps2680/lab05/gallery.html](https://christianrodriguez46.github.io/Coursework/cmps2680/lab05/gallery.html)

Requires: Any modern web browser. No server or build step is needed.

## Concepts

- DOM manipulation
- Click handlers
- Flexbox
