CMPS 3640 · Lab 1

Timing a multithreaded array operation

Times the instructor's array benchmark, which computes cos(A[i]) + sin(B[i]) for 20 million elements either in one loop or split into equal blocks across std::thread workers. Each setting runs ten times and prints the average, and a small Bash script steps through the thread counts so the speedup can be compared.

View code on GitHubREADME

What I did

  • Used the instructor's ArrayOp.cpp (credited to Yi Zhao in its header), which takes the thread count as its only argument and treats 0 as the sequential version.
  • Ran it through runlab, a Bash loop that calls ./ArrayOp with 0, 1, 2 and up to n - 1 threads in a row (bash runlab n).
  • Saved a 2-thread run in output.txt: ten runs averaging about 3.16 seconds.

How to build and run

From the folder with the code:

g++ -O2 -pthread -o ArrayOp ArrayOp.cpp
./ArrayOp 2
bash runlab 5  # threads 0 to 4

Requires: g++ with OpenMP (-fopenmp) and POSIX threads (-pthread), standard on Linux.
