# CMPS 3640: Distributed and Parallel Computation

Concurrency and parallel programming with OpenMP, measuring speedup and synchronization costs.

Languages and tools: C++, OpenMP.

Labs 1 and 2 start from the instructor's array benchmark (`ArrayOp`), which is credited in each file's header.

## Requirements

`g++` with OpenMP (`-fopenmp`) and POSIX threads (`-pthread`), standard on Linux.
