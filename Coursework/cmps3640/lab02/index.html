CMPS 3640 · Lab 2

First OpenMP programs

Two first OpenMP programs. The hello-world program prints Hello(id) World(id) from each of six threads, and their output interleaves differently on every run. ArrayOpOMP.cpp redoes the lab 1 benchmark with a parallel region, but its loop steps by the thread count inside each thread's block, so only one element in NT is computed and larger thread counts look faster than they are.

View code on GitHubREADME

What I did

  • Ran the OpenMP hello world with omp_set_num_threads, changing NT between runs as the source comment lists (2, 3, 4 and 6).
  • Filled in the block bounds marked // START and // END in ArrayOpOMP.cpp, the instructor's OpenMP version of the lab 1 benchmark, so each thread gets its own share of the array.
  • Timed it with different thread counts given on the command line. The program reports the team size it actually got (actThreads) and the time from omp_get_wtime.

How to build and run

From the folder with the code:

g++ -fopenmp -o hello HelloWorldOMP.cpp
./hello

g++ -fopenmp -O2 -o arrayomp ArrayOpOMP.cpp
./arrayomp 4

Requires: g++ with OpenMP (-fopenmp) and POSIX threads (-pthread), standard on Linux.
