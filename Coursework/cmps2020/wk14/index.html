CMPS 2020 · Week 14

Binary search tree and searching

Searching. Homework 3 is a binary search tree of integers that loads 25 sample values, adds one from the user, then finds and optionally deletes a value. Lab 18 searches a sorted list of 25 words by linear search, binary search or substring match from a menu.

View code on GitHubREADME

What I did

  • Wrote the BST class with recursive add_node, find_node, show_node (in order) and destroy_node, and a node count updated as nodes are created and deleted.
  • Wrote delete_node, which finds the node with a loop and replaces a node that has two children with the smallest value in its right subtree.
  • Wrote find_item_linear, find_item_binary and find_matches (using string::find) for lab 18, sorting the list first so binary search works.

How to build and run

From the folder with the code:

g++ -o hw03 hw03_2020TH_ChrRod.cpp
./hw03

g++ -o lab18 lab18_2020TH_ChrRod.cpp
./lab18

Requires: A C++ compiler such as g++ (Linux, macOS, or WSL on Windows).
