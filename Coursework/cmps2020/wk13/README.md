# Recursion, sorting and heaps

**CMPS 2020 Programming II: Data Structures**, Week 13

## What it does

- `lab15_2020TR_ChrRod.cpp` (lab 15) prints and frees the browser-history stack recursively.
- `lab16_2020TH_ChrRod.cpp` (lab 16) times bubble sort, insertion sort and quick sort on random, increasing and decreasing arrays.
- `lab17_2020TH_ChrRodr.cpp` (lab 17) checks whether an array is a max-heap, builds one, and heap sorts it.

## How to run

From this folder:

```bash
g++ -O2 -o lab16 lab16_2020TH_ChrRod.cpp
./lab16

g++ -o lab17 lab17_2020TH_ChrRodr.cpp
./lab17
```

Requires: A C++ compiler such as `g++` (Linux, macOS, or WSL on Windows).

## Concepts

- Recursion
- Sorting algorithms and timing
- Heaps
