# Stacks: array version and postfix calculator

**CMPS 2020 Programming II: Data Structures**, Week 8

## What it does

- `lab09_2020TH_ChrRod.cpp` (lab 9) is the browser-history stack again, this time backed by an array.
- `hw02_2020TH_ChrRod.cpp` (homework 2) is a template `Stack` class used to evaluate a postfix expression passed on the command line.

## How to run

From this folder:

```bash
g++ -o lab09 lab09_2020TH_ChrRod.cpp
./lab09

g++ -o hw02 hw02_2020TH_ChrRod.cpp
./hw02 3 4 +
```

Requires: A C++ compiler such as `g++` (Linux, macOS, or WSL on Windows).

## Concepts

- Array-based stacks
- Class templates
- Postfix evaluation
