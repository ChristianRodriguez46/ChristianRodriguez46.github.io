CMPS 2020 · Week 8

Stacks: array version and postfix calculator

Stacks two ways. Homework 2 is a postfix (RPN) calculator built on a template Stack class that reads its expression from the command line. Lab 9 redoes the browser history stack with a fixed array of 100 entries.

View code on GitHubREADME

What I did

  • Started from the instructor's homework skeleton and finished the loop in solve_rpn: numbers are pushed, and an operator pops two values, applies calc and pushes the result.
  • Added -, x, / and ^ (power, through pow) to calc and is_op, with x standing in for multiplication so the shell does not expand *.
  • Wrote the Stack destructor that frees the remaining nodes.
  • Wrote an array-based Stack for lab 9 that shifts entries to keep the newest at index 0. Its pop returns the oldest entry instead of the newest, which shows in the snapshot.
