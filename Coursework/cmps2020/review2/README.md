# Resizable array (exam practice)

**CMPS 2020 Programming II: Data Structures**, Exam review

## What it does

`r1.cpp` is a `SmartArray` class that doubles its capacity when full, written as practice for the second exam.

## How to run

From this folder:

```bash
g++ -o r1 r1.cpp
./r1
```

Requires: A C++ compiler such as `g++` (Linux, macOS, or WSL on Windows).
