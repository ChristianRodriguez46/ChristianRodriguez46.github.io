Resizable array (exam practice)

Practice for the second exam: a SmartArray class that stores strings in a dynamic array and grows when it fills up. The test in main starts with room for three strings and keeps adding past that.

View code on GitHubREADME

What I did

  • Wrote SmartArray with a constructor that allocates the array, a destructor that frees it, and add and show methods.
  • Wrote the private resize, which copies the strings into a larger array and deletes the old one. It doubles size and then allocates size * 2, so each resize makes four times the room.
  • Tested it in main by adding three strings, then four more past the starting capacity, and printing the array after each batch.

What I used

  • C++
  • Classes
  • Dynamic memory
  • Destructors

Concepts:

  • Dynamic arrays
  • Resizing

Libraries

C++ standard library: iostream.

How to build and run

From the folder with the code:

g++ -o r1 r1.cpp
./r1

Requires: A C++ compiler such as g++ (Linux, macOS, or WSL on Windows).
