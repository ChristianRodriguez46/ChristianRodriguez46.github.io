CMPS 2020 · Week 12

Hash function collisions

A look at hash collisions. The program reads all 172,820 words in enable1.txt, hashes each by summing its letter positions (a = 1, b = 2 and so on) modulo 320, and reports how many words land at every index and which index is busiest.

View code on GitHubREADME

What I did

  • Wrote calcHash, which adds c - 'a' + 1 for each character and takes the sum modulo 320.
  • Counted hits per index in a 320-entry array while reading the word list with fin >> word.
  • Printed the full table and found the index with the most collisions (93, with 1,965 words).
