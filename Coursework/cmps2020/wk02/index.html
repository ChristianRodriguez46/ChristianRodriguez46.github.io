CMPS 2020 · Week 2

Classes and operator overloading

Classes and operator overloading. In lab 1 a point class overloads < and > to shift a point left or right, * to compute the area of the rectangle two points bound, and << to print a point. A practice lab builds a Map from two Point corners.

View code on GitHubREADME

What I did

  • Overloaded < and > as member functions that return a shifted copy of the point.
  • Wrote * and << as friend functions so they can read the private coordinates.
  • Built a Map class from two Point corners in the practice lab and computed its area in calArea.
  • Took in-class notes on access specifiers in untitled.cpp, which does not compile as written (missing semicolons, and main reads private members).
