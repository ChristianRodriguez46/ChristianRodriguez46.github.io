CMPS 2020 · Week 5

Config file parser and templates

Custom exceptions and function templates. Lab 6 reads config.ini line by line and throws a different exception class for each kind of malformed line. Lab 7 uses templates to read and print arrays of integers, doubles and strings, and to average the two numeric arrays.

View code on GitHubREADME

What I did

  • Derived ConfigFileMissingKey, ConfigFileBadKey and ConfigFileMissingSeparator from a ConfigFileError base that extends std::exception, each overriding what().
  • Wrote is_comment, is_name_valid, contains_separator and is_missing_key, and caught each exception type in main, ending with catch (...). Because the key check runs first, a line that starts with = is reported as a bad key.
  • Wrote the templates Input, showArray and average, plus a showArray specialization for string.
  • Called each template with int, double and string arrays of ten values.

How to build and run

From the folder with the code:

./lab06

g++ -o lab07 lab07_2020TH_ChrRod.cpp
./lab07

Requires: A C++ compiler such as g++ (Linux, macOS, or WSL on Windows).
