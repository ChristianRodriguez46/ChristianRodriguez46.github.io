CMPS 2020 · Week 4

Exporting data; credit card validation

Two exercises in polymorphism. Homework 1 saves the same county infection counts as JSON or CSV through two subclasses of an abstract CoronaData class. Lab 5 validates a credit card with the Luhn checksum and per-brand rules, using a factory function to pick the card class.

View code on GitHubREADME

What I did

  • Started from the instructor's sample code for homework 1 and wrote CoronaDataJson and CoronaDataCsv, each overriding the pure virtual save_to_file.
  • Formatted the counts with fixed and setprecision(4) and wrote the JSON brackets and commas by hand.
  • Implemented the Luhn check in check_luhn (the skeleton's extra-credit item), doubling every second digit from the right.
  • Added the Amex and Mastercard classes with their own length, first-digit and security-code rules, and enabled them in the create factory function.
  • Answered the lab 4 questions in lab04_2020TH_ChrRod.txt.
