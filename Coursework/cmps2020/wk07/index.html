CMPS 2020 · Week 7

Linked lists and a linked stack

First steps with linked lists. The in-class lab links five Item structs by hand and walks the list to count, print and search it. Lab 8 models a browser's Back button as a stack of dynamically allocated VisitNodes.

View code on GitHubREADME

What I did

  • Wrote count, show, find and setcounts, each walking the list with a temporary pointer until it reaches NULL.
  • Wrote a Stack class whose push puts a new node at the head and whose pop removes it and returns the page name.
  • Allocated nodes in a private create method that catches bad_alloc, and freed them from the destructor through deallocate.
  • Gave the show function friend access to print the history from newest to oldest.

How to build and run

./ilab01

g++ -o lab08 lab08_2020TH_ChrRod.cpp
./lab08
