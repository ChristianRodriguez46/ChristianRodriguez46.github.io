# Deque and a window manager

**CMPS 2020 Programming II: Data Structures**, Week 10

## What it does

- `lab12_2020TH_ChrRod.cpp` (lab 12) implements a doubly linked deque and derives a `Queue` and a `Stack` from it.
- `lab13_2020TH_ChrRod.cpp` (lab 13) simulates switching between open apps with a circular doubly linked list: launch, close, find, and move to the next or previous window.

## How to run

From this folder:

```bash
g++ -o lab12 lab12_2020TH_ChrRod.cpp
./lab12

g++ -o lab13 lab13_2020TH_ChrRod.cpp
./lab13
```

Requires: A C++ compiler such as `g++` (Linux, macOS, or WSL on Windows).

## Concepts

- Doubly linked lists
- Circular lists
- Inheritance from a container
