# vim skills and shell profiles

**CMPS 2650 Linux Environment and Administration**, Lab 6

## What it is

Moving around and reformatting code in vim, then customizing the shell through `.bash_logout`, aliases and the prompt. `hello.cpp` is the file used for the indenting and folding steps.

## Files

| File | What it is |
|---|---|
| [hello.cpp](hello.cpp) | Short C++ file for practicing re-indenting and folding in vim |

## Try it

From this folder:

```bash
vim hello.cpp     # then =iB inside a block, or zf% on a { to fold it
```

Requires: bash on Linux, macOS or WSL, plus `gcc`/`g++` for the C and C++ files.
