# Bash scripting, part 2

**CMPS 2650 Linux Environment and Administration**, Lab 8

## What it is

Parsing `key=value` arguments, loops and arithmetic, functions, and here-documents.

## Files

| File | What it is |
|---|---|
| [lab8-01.sh](lab8-01.sh) | Adds the values of A=... and B=... arguments |
| [lab8-02.sh](lab8-02.sh) | Factorial with read and a for loop |
| [lab8-03.sh](lab8-03.sh) | Factorial in a function, from an argument or typed input |

## Try it

From this folder:

```bash
bash lab8-01.sh A=100 B=200      # A + B = 300
bash lab8-02.sh
bash lab8-03.sh 5                # 5! = 120
```

Requires: bash on Linux, macOS or WSL, plus `gcc`/`g++` for the C and C++ files.
