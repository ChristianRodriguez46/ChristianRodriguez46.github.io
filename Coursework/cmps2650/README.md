# CMPS 2650: Linux Environment and Administration

The Linux command line, editors and shell scripting, then running a Debian system: users, passwords, storage, services and DNS.

Languages and tools: Bash, vim, grep, sed, awk, Debian.

The course had two parts: the command-line environment (labs 1 to 10, done on the department server) and system administration (admin labs, done on my own Debian virtual machine). The lab handouts are the instructor's and are not included; the answers page restates each task, then shows the commands I used and what they do. Server addresses, other users' information and password hashes are left out.

**Answers page:** [https://christianrodriguez46.github.io/Coursework/cmps2650/](https://christianrodriguez46.github.io/Coursework/cmps2650/). It has every lab: the task in my own words, the commands I used, and what they do.
