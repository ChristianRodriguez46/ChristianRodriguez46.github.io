CMPS 3390 · Lab 1

Version control with Git

A one-line C++ program used as the practice project for a Git and GitHub exercise. The work is in the version-control steps listed in the lab README: committing, branching and merging, pushing and pulling, and forking with pull requests.

View code on GitHubREADME

What I did

  • Built and ran app.cpp, which prints WELCOME TO MY APP!, as the code kept under version control.
  • Wrote a .gitignore that skips executables (*.out, *.exe) and hidden dot files, with an exception that keeps .gitignore itself tracked.
  • Worked through the Git workflow the lab README lists: staging and committing, branching and merging, push, fetch and pull, and forking with pull requests.

How to build and run

From the folder with the code:

g++ -o app app.cpp
./app

Requires: PHP 7.4 or later for the PHP labs (its built-in server is enough). g++ for lab 1.
