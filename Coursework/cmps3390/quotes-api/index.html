CMPS 3390 · Quotes API

Quotes API

A small JSON API that returns a random quote from a book, a movie or a game. The category comes from the query string and is checked against a whitelist, and anything else gets HTTP 400 and a JSON error.

View code on GitHubREADME

What I did

  • Validated $_GET['category'] against the whitelist ["book", "movie", "game"] with in_array, with separate errors for a missing and an unknown category.
  • Loaded docs/<category>.json, decoded it with json_decode and picked an entry with rand.
  • Wrote jsonErr and jsonRes helpers that set the Content-Type: application/json header and the status code before sending the body.
  • Built the file path only from a whitelisted name, so the query string cannot point the script at other files.

How to build and run

From the folder with the code:

php -S localhost:8000

  # in another terminal
curl 'localhost:8000/index.php?category=movie'
  # returns a random quote, e.g. {"quote":"May the Force be with you.","author":"Star Wars"}

Requires: PHP 7.4 or later for the PHP labs (its built-in server is enough). g++ for lab 1.
