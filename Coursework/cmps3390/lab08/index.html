CMPS 3390 · Lab 8

JSON search and replace endpoints

Two PHP endpoints that read a JSON request body and answer with a small HTML page. search.php highlights every whole-word match of a term, and replace.php swaps each whole-word match for new text and highlights the replacement. Both ignore case and answer missing input with HTTP 400.

View code on GitHubREADME

What I did

  • Read the raw request body with file_get_contents('php://input') and decoded it with json_decode.
  • Checked the required fields in a loop (search and text, or find, replace and text) and stopped with htmlError, which sends status 400 and a message such as replace NOT SET.
  • Built a case-insensitive whole-word pattern from preg_quote and \b anchors, and wrapped each match in a yellow <span> with preg_replace_callback and an arrow function.
  • Put the shared helpers in lib.php: htmlError and htmlRes, which wraps the result in an HTML page with status 200.
  • Kept line breaks from the input text by passing the result through nl2br.

How to build and run

From the folder with the code:

php -S localhost:8000

  # in another terminal
curl -X POST localhost:8000/replace.php \
  -d '{"find":"cat","replace":"dog","text":"The cat sat."}'

Requires: PHP 7.4 or later for the PHP labs (its built-in server is enough). g++ for lab 1.
