CMPS 3500 · Lab 2

C++ templates and exceptions

A C++ class template, List, with a fixed capacity of 10 that throws a custom RangeError exception on bad indexes. The test program fills an int list and a double list with as many random values as the command line asks for, and sizes over 10 trigger exceptions that are caught and written to a log file instead of ending the program.

View code on GitHubREADME

What I did

  • Started from the instructor's List template, RangeError class and test program, copied from the course examples.
  • Added the throwing function's name (__func__) to RangeError and its message, so each error says where it came from.
  • Wrapped the add, swap and max calls in main in try/catch blocks, so a size of 12 runs to the end instead of aborting with an uncaught exception.
  • Redirected stderr to a file named log with freopen, starting it with a header line.

How to build and run

From the folder with the code:

make
./lab02 8
./lab02 12  # forces range errors; see the log file

Requires: Linux. Each lab uses a different language toolchain, listed in its README; every folder has a Makefile.
