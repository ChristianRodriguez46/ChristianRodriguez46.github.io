CMPS 3500 · Lab 3

Ada: strong typing and concurrent tasks

Two Ada programs run on the course server. testada tours Ada's strong typing, scoping, parameter modes, arrays and file I/O, and dogspa simulates a dog kennel as a concurrent task that accepts drop-off, pickup and treat requests through a selective wait with guards.

View code on GitHubREADME

What I did

  • Ran the instructor's testada.adb, which reads infile.txt, writes outfile.txt and shows nested scopes, in/out parameters and explicit type conversion.
  • Completed the instructor's dogspa.adb: changed the dropoffDog entry to take a biter flag and a name, and turned biters away with a message.
  • Read the dog names from names.txt into an array of unbounded strings and chose a random name that is not already in the kennel for each drop-off.
  • Wrote the pickupDog logic that removes the dog and shifts the rest of the array left.
  • Wrote a Makefile that builds both programs with gcc -c, gnatbind and gnatlink.

How to build and run

From the folder with the code:

sudo apt install gnat  # once
make
./testada
./dogspa

Requires: GNAT, the GCC Ada compiler.
