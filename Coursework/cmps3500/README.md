# CMPS 3500: Programming Languages

How programming languages work, explored by writing the same kinds of programs in C, Ada, Fortran, Prolog and C#.

Languages and tools: C, C++, Ada, Fortran, Prolog, C#.

Each lab explores one language by running and modifying example programs. The `*_output.log` and `*_time.log` files are recordings of the lab session made with the Linux `script` command; replay one with `scriptreplay lab02_time.log lab02_output.log`.

## Requirements

Linux. Each lab uses a different language toolchain, listed in its README; every folder has a `Makefile`.
