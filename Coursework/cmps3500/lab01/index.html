CMPS 3500 · Lab 1

C on the Linux server

A first session on the course's Linux server: write and back up a text file, look at who is logged in and which processes are running, end a stray login shell, and compile and run a C hello-world program. The whole session was recorded with script so it can be replayed.

View code on GitHubREADME

What I did

  • Wrote lab1.txt in vim, copied it to a backup and moved the backup into a backups folder locked down with chmod 700.
  • Used who and ps -u $USER to find a second login shell and ended it with kill, then with kill -9 when a later shell ignored the plain signal.
  • Wrote hello.c, compiled it with gcc -g and ran it.
  • Recorded the session with script -T, which also saves the timing file used by scriptreplay.

How to build and run

From the folder with the code:

gcc -o hello hello.c
./hello

Requires: Linux. Each lab uses a different language toolchain, listed in its README; every folder has a Makefile.
