# C on the Linux server

**CMPS 3500 Programming Languages**, Lab 1

Read this lab with snapshots and notes on every file: [https://christianrodriguez46.github.io/Coursework/cmps3500/lab01/](https://christianrodriguez46.github.io/Coursework/cmps3500/lab01/)

## What it does

Compiles and runs `hello.c` on the course server, with the terminal session recorded in `lab1_output.log`.

## How to run

From this folder:

```bash
gcc -o hello hello.c
./hello
```

Requires: Linux. Each lab uses a different language toolchain, listed in its README; every folder has a `Makefile`.

## Concepts

- Compiling C
- Recording a terminal session with `script`
