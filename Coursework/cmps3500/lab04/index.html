CMPS 3500 · Lab 4

Fortran 77

Fortran on the course server: array statistics with formatted output (DO loops in array1.f, Fortran 90 whole-array operations in array2.f and allocatable arrays in array3.f), a circle calculator, and two debugging challenges about fixed-format columns and implicit typing.

View code on GitHubREADME

What I did

  • Built and ran the instructor's array and circle examples with the provided Makefile.
  • Fixed all 13 tests in formatfix.f by moving statements, labels, comments and continuation marks into the right fixed-format columns, so it compiles and prints OK 1 to OK 13.
  • Fixed implicitbug.f, which printed an average of 0 and a variance of 38.5, by declaring every variable and correcting typos as the task asked; it now prints 5.5 and 8.25.

What I used

  • Fortran

  • Fixed-format source

Concepts:

Libraries

Linked with libm.a (prebuilt library in this folder).

How to build and run

From the folder with the code:

sudo apt install gfortran  # once
make
./array1

Requires: gfortran.
