# Fortran 77

**CMPS 3500 Programming Languages**, Lab 4

Read this lab with snapshots and notes on every file: [https://christianrodriguez46.github.io/Coursework/cmps3500/lab04/](https://christianrodriguez46.github.io/Coursework/cmps3500/lab04/)

## What it does

Short Fortran 77 programs: three array examples (`array3.f` reads `array3.in`), a circle area calculator with and without input, fixed-format formatting challenges (`formatfix.f`), and a demonstration of bugs caused by Fortran's implicit typing (`implicitbug.f`).

## How to run

From this folder:

```bash
sudo apt install gfortran   # once
make
./array1
```

Requires: `gfortran`.

## Concepts

- Fortran 77 fixed format
- Implicit typing
- Formatted I/O
