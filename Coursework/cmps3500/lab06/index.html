CMPS 3500 · Lab 6

Prolog: facts, rules and queries

Logic programming in GNU Prolog. The main program turns nine English statements about four animals into rules so the query likes(X,Y) can infer who likes whom, and adds rules for the largest of three numbers and the Towers of Hanoi move count. The other files are the instructor's examples of family trees, logical arguments, nested predicates and recursion.

View code on GitHubREADME

What I did

  • Wrote the nine rules in lab06.pl (fur, rat, cat, meows, bird, dog and three likes rules) on top of the given facts.
  • Added max2 and max3, and a recursive moves(N,T) that counts the moves needed to solve the Towers of Hanoi (31 for 5 discs).
  • Compiled lab06.pl with gplc into a program whose initialization directives run the three queries and exit.
  • Loaded the instructor's family.pl in the gprolog interpreter and ran its queries.

How to build and run

From the folder with the code:

sudo apt install gprolog  # once
make
./lab06

Requires: GNU Prolog (gprolog and gplc).
