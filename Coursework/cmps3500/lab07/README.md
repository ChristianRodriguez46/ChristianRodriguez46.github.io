# C# compared with C++

**CMPS 3500 Programming Languages**, Lab 7

## What it does

`lab07.cs` computes areas of shapes through an `IShape` interface. `sample1.cs` to `sample7.cs` show other C# features, and `C#_v_C++.txt` summarizes how the two languages differ (entry point, parameter passing, garbage collection, properties and interfaces).

## How to run

From this folder:

```bash
sudo apt install mono-mcs   # once
make
mono lab07.exe
```

Requires: Mono (`mcs` and `mono`) or the .NET SDK.
