CMPS 3500 · Lab 7

C# compared with C++

C# with the Mono compiler: seven sample programs on namespaces, arrays, properties, interfaces, parameter modes and events, notes on how C# differs from C++, and a shape program built on an IShape interface. The lab07.cs in this folder is the starter file; the recorded session shows the finished version printing each shape's area.

View code on GitHubREADME

What I did

  • Built the instructor's seven C# samples with mcs through the provided Makefile.
  • Completed lab07.cs on the course server: constructors, Area properties and Display methods for Rectangle, Triangle and Circle, and a Radius property with get and set.
  • Worked through the compiler errors along the way (properties with no accessors, a misspelled Console.Writeline) until it built and ran under mono.

How to build and run

From the folder with the code:

sudo apt install mono-mcs  # once
make sample5
mono sample5.exe

Requires: Mono (mcs and mono) or the .NET SDK.
