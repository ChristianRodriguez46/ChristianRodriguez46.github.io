CMPS 2010 · Lab 5

File processing and prime numbers

Two console programs. lab5-1.cpp copies a text file in uppercase with the vowels removed and spaces turned into underscores. lab5-2.cpp checks whether a whole number is prime and lists its factors.

View code on GitHubREADME

What I did

  • Read the input file one character at a time with get() and wrote each kept character with put().
  • Took both file names as command-line arguments, printing a usage line when they are missing and an error when a file cannot be opened.
  • Split the prime checker into getWholeNumber, which fills a reference parameter and re-prompts until it gets a non-negative number, isPrime and printFactors.
  • Kept the earlier draft, lab5-2-alt.cpp, which prints its verdict from inside isPrime.

What I used

  • C++
  • File streams
  • Command-line arguments
  • cctype

  • Reference parameters

Concepts:

  • File streams (ifstream, ofstream)
  • Command-line arguments

Libraries

C standard library: stdbool.h.

C++ standard library: cctype, cmath, cstdio, fstream, iostream.

How to build and run

From the folder with the code:

g++ -o lab5-1 lab5-1.cpp
./lab5-1 input.txt output.txt

g++ -o lab5-2 lab5-2.cpp
./lab5-2

Requires: A C++ compiler such as g++ (Linux, macOS, or WSL on Windows).
