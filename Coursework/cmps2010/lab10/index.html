CMPS 2010 · Lab 10

Monster class

Lab 9's monster cards rebuilt around a Monster class. The struct becomes a class with private fields and a getter and setter for each, declared in Monster.h and defined in Monster.cpp, and Main.cpp uses them to generate monsters and write their cards.

View code on GitHubREADME

What I did

  • Turned the Monster struct into a class with private fields and a get/set pair for each one, split across Monster.h and Monster.cpp.
  • Marked the getters const.
  • Updated genMonster, displayMonster and makeMonsterCards in Main.cpp, carried over from the lab 9 skeleton, to go through the setters and getters.

How to build and run

From the folder with the code:

g++ -o monster_cards Main.cpp Monster.cpp
./monster_cards

Requires: A C++ compiler such as g++ (Linux, macOS, or WSL on Windows).
