# Monster class

Read this lab with snapshots and notes on every file: [https://christianrodriguez46.github.io/Coursework/cmps2010/lab10/](https://christianrodriguez46.github.io/Coursework/cmps2010/lab10/)

## What it does

Rebuilds lab 9 with a `Monster` class split across `Monster.h` and `Monster.cpp`, with getters and setters. `Main.cpp` generates random monsters and writes a card for each into `monsters/`.

## How to run

From this folder:

```bash
g++ -o monster_cards Main.cpp Monster.cpp
./monster_cards
```

Requires: A C++ compiler such as `g++` (Linux, macOS, or WSL on Windows).
