CMPS 2010 · Lab 6

Arrays from files and random names

Arrays filled from a file and from random picks. lab6-1.cpp reads up to 100 integers from numbers.txt and prints them in reverse, and extralab6.cpp adds their sum and average. lab6-2.cpp prints random first and last names, and Fall25/ holds 2025 rewrites of both programs with a Makefile.

View code on GitHubREADME

What I did

  • Read the numbers into an int array with while (inputFile >> array[count]) and printed them with a loop that counts down from count - 1.
  • Added the sum and average in extralab6.cpp.
  • Wrote genFirstName and genLastName, which pick from ten-name arrays with rand() % 10, and took the name count from argv[1] with atoi (10 when no argument is given).
  • Rewrote both programs in fall 2025 with a Makefile that builds p1 and p2 with -Wall.

How to build and run

From the folder with the code:

g++ -o lab6-1 lab6-1.cpp
./lab6-1 numbers.txt

g++ -o lab6-2 lab6-2.cpp
./lab6-2 5

  # or, for the fall 2025 versions
cd Fall25 && make
./p1 numbers.txt
./p2 5

Requires: A C++ compiler such as g++ (Linux, macOS, or WSL on Windows).
