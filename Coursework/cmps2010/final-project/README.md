# Restaurant reviews

**CMPS 2010 Programming Fundamentals**, Final project

Read this lab with snapshots and notes on every file: [https://christianrodriguez46.github.io/Coursework/cmps2010/final-project/](https://christianrodriguez46.github.io/Coursework/cmps2010/final-project/)

## What it does

Asks how many restaurants to review, then collects each one's name, type, style, number of locations and a score out of 5. The reviews are stored in a dynamic array of `Restaurant` objects and saved to `reviews.csv`.

## How to run

From this folder:

```bash
g++ -o reviews Main.cpp Restaurant.cpp
./reviews
```

Requires: A C++ compiler such as `g++` (Linux, macOS, or WSL on Windows).
