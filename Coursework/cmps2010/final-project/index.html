CMPS 2010 · Final project

Restaurant reviews

A restaurant review program. It asks how many restaurants to review, collects each one's name, type, style, number of locations and a score out of 5 into a dynamic array of Restaurant objects, and saves them as lines in reviews.csv.

View code on GitHubREADME

What I did

  • Wrote the Restaurant class with private fields, a default constructor, setters and a toCSV method that joins the fields with commas.
  • Read multi-word answers with getline, calling cin.ignore() to skip the newline left by the previous number.
  • Stored the reviews in an array allocated with new Restaurant[size] and freed it with delete[].
  • Wrote outputReviews, which writes one CSV line per restaurant to reviews.csv.

Headers in this folder: Restaurant.h.

How to build and run

From the folder with the code:

g++ -o reviews Main.cpp Restaurant.cpp
./reviews

Requires: A C++ compiler such as g++ (Linux, macOS, or WSL on Windows).
