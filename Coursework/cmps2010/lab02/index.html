CMPS 2010 · Lab 2

Mad Libs and math functions

Two programs that read from the keyboard. lab2-1.cpp asks for seven words and phrases and prints a short Mad Libs story built from them. lab2-2.cpp reads a decimal number and prints its sine, cosine, tangent, exponent, natural log and square root in right-aligned columns.

View code on GitHubREADME

What I did

  • Read single words with cin >> and a whole phrase with getline, calling cin.ignore() first to drop the leftover newline.
  • Built the story by splicing the answers into fixed sentences.
  • Called sin, cos, tan, exp, log and sqrt from <cmath>.
  • Lined up the results with setw, right, showpoint and setprecision(7) from <iomanip>.

What I used

  • C++
  • cin and getline
  • cmath
  • iomanip formatting

Concepts:

  • Reading input with cin and getline
  • <cmath> functions
  • Formatting with setw and setprecision

Libraries

C++ standard library: cmath, iomanip, iostream, string.

How to build and run

From the folder with the code:

g++ -o lab2-1 lab2-1.cpp
./lab2-1

g++ -o lab2-2 lab2-2.cpp
./lab2-2

Requires: A C++ compiler such as g++ (Linux, macOS, or WSL on Windows).
