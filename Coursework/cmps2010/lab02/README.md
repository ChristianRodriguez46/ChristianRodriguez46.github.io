# Mad Libs and math functions

**CMPS 2010 Programming Fundamentals**, Lab 2

## What it does

- `lab2-1.cpp` asks for a name, an occupation, an adjective, a verb, a number, an animal and a phrase, then prints a short story built from the answers.
- `lab2-2.cpp` reads a decimal number and prints its sine, cosine, tangent, exponent and log in aligned columns.

## How to run

From this folder:

```bash
g++ -o lab2-1 lab2-1.cpp
./lab2-1

g++ -o lab2-2 lab2-2.cpp
./lab2-2
```

Requires: A C++ compiler such as `g++` (Linux, macOS, or WSL on Windows).

## Concepts

- Reading input with `cin` and `getline`
- `<cmath>` functions
- Formatting with `setw` and `setprecision`
