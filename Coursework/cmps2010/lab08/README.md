# Pointers: inventory and money game

**CMPS 2010 Programming Fundamentals**, Lab 8

## What it does

- `guided-lab8.cpp` keeps a small inventory (book, pencil, paper) and a hand. A menu lets you grab an item, move it, or show everything, passing the items around with pointers.
- `Money-Game.cpp` asks how many pennies, nickels, dimes and quarters you have and tells you whether the total lands between $1.00 and $2.00.

## How to run

From this folder:

```bash
g++ -o guided guided-lab8.cpp
./guided

g++ -o money Money-Game.cpp
./money
```

Requires: A C++ compiler such as `g++` (Linux, macOS, or WSL on Windows).

## Concepts

- Pointers and pointer parameters
- Functions returning pointers
