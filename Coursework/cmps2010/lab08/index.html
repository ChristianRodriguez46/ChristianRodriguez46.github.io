CMPS 2010 · Lab 8

Pointers: inventory and money game

Two programs about pointers and input checks. guided-lab8.cpp tracks whether a book, a pencil and a sheet of paper are on the floor, chair or desk, and uses a pointer as the hand that holds one of them. Money-Game.cpp adds up a handful of coins and says whether the total lands between $1.00 and $2.00.

View code on GitHubREADME

What I did

  • Built the guided part of the lab around grab, which returns the address of the chosen item (or nullptr), and move, which writes the new location through that pointer.
  • Wrote showAll, which compares the hand pointer with each item's address to report what is held.
  • Mapped location codes to names in show and drove everything from a do/while menu.
  • Totaled the coins in Money-Game.cpp with const coin values and loops that re-read any negative count.

What I used

  • C++

Concepts:

  • Pointers and pointer parameters

Libraries

C++ standard library: iostream, string.

How to build and run

From the folder with the code:

g++ -o guided guided-lab8.cpp
./guided

g++ -o money Money-Game.cpp
./money

Requires: A C++ compiler such as g++ (Linux, macOS, or WSL on Windows).
