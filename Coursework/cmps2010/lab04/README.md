# Fruit inventory menu

**CMPS 2010 Programming Fundamentals**, Lab 4

## What it does

`lab4-1.cpp` is a menu-driven inventory for apples, bananas and oranges. It shows the current stock, lets you update an item, and repeats until you choose to quit, rejecting invalid options.

## How to run

From this folder:

```bash
g++ -o lab4-1 lab4-1.cpp
./lab4-1
```

Requires: A C++ compiler such as `g++` (Linux, macOS, or WSL on Windows).
