CMPS 2010 · Lab 4

Fruit inventory menu

A menu-driven fruit stand. It shows the stock of apples, bananas and oranges, lets the user buy a quantity of one fruit at a time, and prints the total owed on quit.

View code on GitHubREADME

What I did

  • Kept the menu in a while (!quit) loop and handled each choice in a switch.
  • Validated the menu choice and the quantity with loops that call cin.clear() and cin.ignore() before asking again, rejecting quantities below 1 or above the stock.
  • Subtracted each purchase from the stock and added its cost to a running total using const prices ($1.00 apples, $0.75 bananas, $1.25 oranges).

How to build and run

From the folder with the code:

./lab4-1

Requires: A C++ compiler such as g++ (Linux, macOS, or WSL on Windows).
