# CMPS 2010: Programming Fundamentals

Procedural and object-oriented C++: control structures, functions, arrays, file I/O, pointers, dynamic memory and classes.

Languages and tools: C++.

## Requirements

A C++ compiler such as `g++` (Linux, macOS, or WSL on Windows).
