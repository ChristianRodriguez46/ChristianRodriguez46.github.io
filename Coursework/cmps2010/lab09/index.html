CMPS 2010 · Lab 9

Monster cards with structs

Random monster cards. A Monster struct holds a name, type, color and counts of eyes, arms and legs. The program prints one sample monster, asks how many more to make, and writes each one to its own card file in monsters/.

View code on GitHubREADME

What I did

  • Started from the instructor's skeleton, which supplied the Monster struct, the name, type and color lists, genRandom and displayMonster, and completed its three TODOs.
  • Filled in genMonster with the random generators, giving 0 to 15 eyes, arms and legs.
  • Wrote makeMonsterCards, which opens monsters/Monsters_<name>.txt for each monster with an ofstream and writes the card.
  • Asked for a count in main, allocated the monsters with new Monster[count], and freed them with delete [].

Libraries

C++ standard library: cstdlib, fstream, iostream, string.

How to build and run

From the folder with the code:

g++ -o monster monster.cpp
./monster

Requires: A C++ compiler such as g++ (Linux, macOS, or WSL on Windows).
