CMPS 2010 · Lab 11

Monster class with constructors

The Monster class gains constructors. The default constructor is meant to fill in a random monster from the lists in GLOBALS.h, a second constructor sets every field, and toString formats the card that Main.cpp writes into monsters/.

View code on GitHubREADME

What I did

  • Started from the instructor's skeleton (Main.cpp, Monster.h and GLOBALS.h) and completed the three TODOs in Monster.cpp.
  • Wrote the default constructor to fill the fields from the private genName, genType, genColor and genRandom helpers. Its last line assigns the random number to type instead of legs, so the cards show a blank type and an unset leg count.
  • Wrote the six-argument constructor, which copies its parameters into the fields with this->.
  • Finished toString, converting the counts with std::to_string.

How to build and run

From the folder with the code:

g++ -o monster_cards Main.cpp Monster.cpp
./monster_cards

Requires: A C++ compiler such as g++ (Linux, macOS, or WSL on Windows).
