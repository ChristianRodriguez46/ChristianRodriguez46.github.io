About Breakaway

A top-down hockey shootout against an AI goalie, built in plain JavaScript and Canvas.

Play Breakaway View code

What it is

Breakaway is a hockey shootout. I skate in from center ice, deke, shoot, and try to score on an AI goalie. Each round is 5 attempts and I need 3 goals to reach the next round. The goalie starts at Rookie and gets sharper, up to All-Star. I built it for this portfolio, and it plays in the browser on a laptop or a phone with nothing to install.

How to play

I pick one of three control schemes in Settings. The default is Hold to charge.

P or Escape pauses. M turns sound on or off. I have 8 seconds per attempt. A goal is 100 points, and 50 more if the goalie bit on a deke first. Aim with mouse needs a mouse or a touch screen.

How I built it

I used plain JavaScript ES modules and the Canvas 2D API. There are no runtime dependencies and no build step, so the game is published the same way as the rest of my site: commit and push to GitHub Pages.

The code is split in two. src/core/ holds every rule (physics, collisions, goalie AI, scoring, round rules, saved-data checks) as plain functions with no browser code, and random numbers come in as a seeded function. src/browser/ is a thin shell that runs a fixed-step loop (120 steps a second inside requestAnimationFrame), reads input, draws the canvas, plays synthesized sound, saves settings and announces results to screen readers. That split lets me test the rules with the same seed every time, and a ?seed= URL parameter does the same thing in the browser.

Run it locally

I use WSL2 Ubuntu. The game needs a web server because browsers won't load ES modules from file://.

mkdir -p ~/REPO && cd ~/REPO
git clone https://github.com/ChristianRodriguez46/ChristianRodriguez46.github.io.git
cd ChristianRodriguez46.github.io
python3 -m http.server 4101

Then I open http://localhost:4101/Projects/Breakaway/ in my browser. I serve the repository root, not the game folder, so the shared site styles load.

Privacy

The game saves two localStorage keys, breakaway.settings and breakaway.best_scores, on your own device. Nothing is sent anywhere. The page has no analytics, no cookies and no requests to other sites. Settings has a button that clears both keys.
